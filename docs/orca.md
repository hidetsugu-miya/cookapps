# Orca

Orca は、エージェントを動かすデスクトップアプリです。

## 一覧

サイドメニューの Orca のアイコンで、Orca のプロジェクトを一覧する（状態のアイコンとセッション数を出し、SSH の接続先も並べる）。
作業中のセッションがあるプロジェクトは上に集め、入った順に固定する（作業が進んでも入れ替わらず、新しく作業が始まったものが先頭に入る）。その下に、セッションはあるが作業中ではないプロジェクトを並べ、セッションの無いプロジェクトはその下に並べる（どちらも最近動いた順）。
プロジェクトの行の矢印で、そのプロジェクトのセッションの行を開閉する（行は 1 段字下げして並ぶ。複数のプロジェクトを同時に開ける）。
最初は作業中のプロジェクトがすべて開いていて、閉じたプロジェクトも、新しいセッションが作業を始めると開き直す。
行を押すとそのタブを選び、右のペインでタブを押すと、その行が選ばれる。
一覧の上の検索欄に打った文字で、プロジェクトと SSH の接続先を名前で絞り込む（Orca 画面のどこにいても Cmd+J で検索欄に移れ、↓↑で行を動き、Enter で選び、Escape で消す）。
入力待ちと、完了や中断で止まって未確認のセッションの件数はサイドメニューのアイコンに出す。作業中のセッションがある間は、アイコンが黄色になってゆっくり明滅する。一覧の幅はドラッグで変えられる。

### 接続先

接続先は左ペインの下端で、このマシンか Orca に保存したサーバーから選ぶ（`orca` CLI と Orca のペアリング情報を使う。アプリは履歴を保存しない）。

## セッション

右のペインではプロジェクトのセッションをタブで切り替え、タブから閉じられる。
どのタブもターミナルで、Claude のセッションにもそのまま打ち込める。
右のペインのタブ列の右端の＋から、「Claude を起動」か「ターミナルを開く」を選ぶと、左ペインで選んでいるプロジェクト（か SSH の接続先）の worktree で始める。
worktree が 2 つ以上あるときは、選ぶ画面を出す。
始めたセッションとターミナルは一覧に現れるとタブで開く。
＋の 3 つ目の「スクラッチパッド」は、メモのファイルを作って開く（[スクラッチパッド](#スクラッチパッド)）。

## ターミナル

保存したサーバーが接続先のときは、Orca が送るターミナルの出力を描く（色も出る）。
ターミナルはいつもペインの大きさに合わせて描く。
このマシンが接続先のときは、Orca が出力を送れないので、画面を毎秒読んで写す。
色は出ず、`claude` のような全画面のプログラムは近似になる。

### コピー

`claude` のようにマウスを使うプログラムでは、ドラッグで選んだ文字列をプログラムが送り、それがクリップボードに入る。
入らなかったときは、⌘C か「編集 > コピー」で入る。
Option を押しながらドラッグすると、プログラムではなくターミナル側で文字を選べる。

### ファイル

ターミナルには、ファイルを貼り付けるか、ドロップできる。画像でも、画像でないファイルでもよい（Finder でコピーしたファイルも貼り付けられる）。
ファイルは、そのセッションの worktree の `.orca/drops/` に、元の名前で置かれる。同じ名前があるときは、`名前 copy.拡張子` のように名前を変える。
置いたファイルのパスがターミナルに入力される（Claude がそのパスからファイルを読む）。画像のパスは貼り付けとして入力し、画像でないファイルのパスは打ち込む。
このマシンの worktree と、保存したサーバーの worktree で使える。SSH の接続先の worktree と、ファイルを書く権限のないペアリングでは使えない。
20 MiB まで置け、置いたファイルは自動では消えない。読めないファイル（フォルダなど）を含むときは、どれも置かない。

### ターミナルの配色

設定の「Orca」タブの「ターミナルの配色」で、ターミナルの配色を選ぶ。
「外観」で「システムに合わせる」「ライト」「ダーク」から選ぶ。
「ライト」か「ダーク」にすると、システムの外観に関係なく、そのテーマで描く。
ライトとダークのテーマは別々に選ぶ。
「システムに合わせる」のときは、システムの外観に合わせて切り替わる（Orca の外観の設定には合わせない）。
選べるのは Orca の組み込みのテーマで、色の見本が出る。
初めての選択は、この Mac の Orca の設定から取る（読めたときの 1 回だけ。Orca の設定は読むだけで、書き換えない）。
Orca に足したテーマや、組み込みにないテーマのときは、ライトは Builtin Tango Light、ダークは Ghostty Default Style Dark になる。
Ghostty の設定を取り込んでいても、色はここで選んだテーマを使う。
フォントは、設定の「フォント」タブでターミナルの書体を選んだときはそれを使い、「Ghostty の設定に従う」のままなら Ghostty の設定を使う（キーは Ghostty の設定のまま）。

## ファイルとエディタ

「ファイル欄」のボタンで、選んでいるタブの worktree のファイルを木で出す。
タブが無いときは、左の一覧で選んでいるプロジェクトの主の worktree（リポジトリ本体のフォルダ）を出す。
ファイルやフォルダの行を右クリックすると、「パスのコピー」と「相対パスをコピー」のメニューが出る。
メニューには、作る、動かす、消す項目もある（[ファイルの操作](#ファイルの操作)）。
ファイルの行のメニューには「ダウンロード」もある。押すと保存ダイアログが出て、選んだ場所にそのファイルをこの Mac へ保存する（保存した環境のファイルも同じ）。
ボタンは、ファイル欄を隠しているときは右上のペインのタブ列の右端に、出しているときはファイル欄の上の段の右端にある。
フォルダは押すと開き、中身を Orca から読む。もう一度押すと閉じる。
一度読んだフォルダは、開き直しても読み直さない。
ディスクでファイルが増えたり減ったりした分は、ウィンドウにフォーカスが戻ったときに出る。そのとき、ルートと開いているフォルダを読み直す（ファイル欄を隠している間は読まない）。読み直すボタンは無い。
git が無視するファイルとフォルダは、薄い斜体で出す（一覧を先に出し、斜体は少し遅れて付く）。
ファイルをダブルクリックする（か、選んで Enter を押す）と、タブで開いて、その場で書き換えられる。
同じファイルをもう一度開くと、そのタブを選ぶ。
入力が止まって、設定の「Orca」タブの「エディタ」の「自動保存までの時間」（100 から 3000 ms、初めは 1000 ms）が過ぎると、自動で保存する。保存のボタンはない。
エディタの書体と大きさは、設定の「フォント」タブで選ぶ。
本文の左には行番号が出る。行番号は選択にもコピーにも入らない。
未保存の入力があるタブには、印が付く。
タブを閉じるときと、ウィンドウを閉じるときも、入力があれば保存する。
開く前に読んだ内容とディスクのファイルが違っていたら（別のところで書き換えられたか、消えたとき）、上書きしない。
そのときは見出しに理由が出て、入力は画面に残り、そのタブはもう保存しない。
ファイルを閉じて開き直すと、ディスクの内容を読み直す。

Markdown のファイルは、見出し、リスト、表、コード、チェックリストを文書の形で描くリッチな表示で開く。
エディタの見出しの右端の 2 つのボタンで、ソース（`<>`）とリッチな表示（鉛筆）を切り替える。選んだ方は、タブを閉じるまで残る。
リッチな表示のまま書き換えられ、ソースと同じく自動で保存する。片方で打った内容は、切り替えるともう片方に出る。
保存するときは、変えた行だけをファイルに入れる。触っていない行の書き方（箇条書きの記号、空白など）と、先頭のフロントマターはそのまま残る。
書き方をそのまま残せないファイルは、ソースで開き、リッチな表示は読むだけになる。書き換えが元の行に当てられなかったときは、ソースに切り替えてエラーを出す。
リッチな表示では、外部の画像は読み込まない。

開けるのは、384 KiB までの UTF-8 のテキストで、改行が LF だけか、全部の行が CRLF のファイルだけ。
バイナリのファイル、UTF-8 でないファイル、改行が混ざっているファイルは、開けない。
このマシンの worktree と、保存したサーバーの worktree で使える。SSH の接続先の worktree では使えない。

ファイル欄の見出しのブランチ名を押すと、真下にブランチの一覧が開く。
一覧は「ローカル」と「リモート」に分かれ、今のブランチに印が付く。
別の worktree で使っているブランチは薄く出て、選べない。
上の欄に打つと一覧を絞り込み、リモートのブランチはその文字で探す。
ブランチを選ぶと、その worktree をそのブランチに切り替える。リモートのブランチを選ぶと、それを追うローカルのブランチを作って切り替える。
切り替えると、ファイル一覧と見出しを読み直す。開いているタブは閉じない。
コミットしていない変更があるときや、マージの途中、セッションが動いているときなど、Orca が断ったときは、その文言が出る。
新しいブランチはここでは作れない。SSH の接続先の worktree では、ブランチ名は押せない。

### ファイルの操作

フォルダの行を右クリックすると、メニューの先頭に「新規ファイル」と「新規フォルダー」が出る。
選ぶと、そのフォルダが開き、中の先頭に名前の欄が出る。Enter で作り、Escape か空の名前でやめる。
木の何もないところを右クリックしても同じ 2 つが出て、worktree の直下に作る。
新しいファイルは、エディタのタブで開く。同じ名前があるときは「同じ名前があります」と出て、何も作らない。

ファイルやフォルダの行を右クリックして「移動・名前の変更」を選ぶと、行がその場で worktree からのパスの欄になり、名前の部分が選ばれる。
書き換えて Enter を押すと、そのパスへ動かす。途中の無いフォルダは作る。Escape でやめる。
行をドラッグして、フォルダの行に落としても動かせる。木の何もないところに落とすと、worktree の直下へ動く。閉じたフォルダは、上で少し止まると開く。
移動先に同じ名前があるときは上書きせず、「同じ名前があります」と出る。
動かしたファイルを開いているタブは、入力を残したまま、新しいパスになる。

メニューの最後の赤い「削除」は、「{名前} を完全に削除します。元に戻せません。」の確認を出し、「削除」を押すと消す。
ゴミ箱には入らず、元に戻せない。フォルダは中身ごと消える。
消したファイルを開いているタブは、保存せずに閉じる。

作る、動かす、消すのあとは、そのフォルダを読み直す。SSH の接続先の worktree では使えない。

### スクラッチパッド

右のペインの＋の「スクラッチパッド」は、worktree の `.orca/scratchpad/` にメモのファイルを作り、エディタのタブで開く。
選ぶと、＋の下に名前の欄が出る。`.orca/scratchpad/` は固定で、名前は初め `memo.md`。拡張子は自由に変えられる。
Enter か「作って開く」で作り、Escape か「やめる」でやめる。
同じ名前のファイルがあるときは、作らずにそのファイルを開く。
worktree が 2 つ以上あるときは、先に選ぶ画面を出す。SSH の接続先の行を選んでいる間は選べない。

### 履歴

ファイル欄の上の段の左の 2 つのアイコン、「ファイル」と「履歴」で、ファイルの木と git の履歴を切り替える。
起動したときはファイルが出ている。選んだ方は、どの worktree でも同じで、アプリを終了するまで残る。
履歴を出しているときにウィンドウにフォーカスが戻ると、履歴を初めから読み直す。読み直すボタンは無い。
履歴は、ファイル欄が出している worktree のコミットを、HEAD から新しい順に 50 件ずつ並べる。行には件名、短い ID、日時が出て、マウスを乗せると作者の名前が出る。
一覧の末尾までスクロールすると、続きを読む。別の worktree に移ると、その worktree の一覧を読み直す。ブランチを切り替えたときも読み直す。
コミットを押すと、一覧の下に、そのコミットで変わったファイルが出る。行には、変わり方（M 変更、A 追加、D 削除、R 名前の変更、C コピー）、名前、フォルダ、増えた行と消えた行の数が出る（バイナリのファイルには数が出ない）。5,000 件を超える分は「ほか N 件」と出る。
ファイルをダブルクリックする（か、選んで Enter を押す）と、そのファイルの差分を作業ペインのタブで出す。左が親のコミットのファイル、右がそのコミットのファイルで、見た目とボタンは、ファイルの右クリックの「差分を表示」で出す HEAD との差分と同じ。
タブの名前と見出しには、コミットの短い ID が付く。同じコミットの同じファイルをもう一度開くと、そのタブを選んで読み直す。
履歴は読むだけで、worktree には何も書かない。SSH の接続先の worktree では履歴は出ない。

## Orca に渡す

開いているメール、Slack のスレッド、Todo の内容を、その画面の右ペインから Orca に渡す。
ペインは上から、送り先、プロジェクト、worktree のチップ、渡す内容のカード、指示の欄の順に並ぶ。
始めるのは新しいセッションだけで、動いているセッションには渡せない。
送り先（このマシンか、保存したサーバー）と、その中のプロジェクトを選ぶ。
プロジェクトのメニューの上の検索欄に打った文字で、プロジェクトを名前で絞り込む（↓↑で行を動き、Enter で選び、Escape で閉じる）。
送り先を選んでも、Orca の画面で選んでいる接続先は変わらない。

### worktree

worktree のチップのメニューには、選んだプロジェクトの worktree が並ぶ。
プロジェクト本体のフォルダ（default）が先頭で、「新規作成」が最後に付く。
各行は名前と、その下に今そこで開いているブランチを出す。チップは「名前 ・ ブランチ」と出る。
上の検索欄に打った文字で、名前とブランチを絞り込む。
既存の worktree を選ぶと、そのフォルダでセッションを始める。渡すときに、ブランチは切り替えない。

「新規作成」を選ぶと、チップの下に枠が出て、名前、作成元、ブランチを決める。
名前は、新しい worktree の名前。
作成元は、新しい worktree の元にするブランチで、ローカルとリモートのブランチの一覧から選ぶ。選ばなければ、Orca の既定になる。
ブランチは、「新しいブランチ」か「既存のブランチ」のどちらか。
「新しいブランチ」では、その名前を書く。空なら、名前は Orca が決める。
「既存のブランチ」では、一覧から選ぶ。別の worktree が使っているブランチと、本体のフォルダが今開いているブランチは選べない。作成元は選べなくなる。
既存のブランチを選んだとき、Orca がそのブランチを開くかどうかは、まだ実機で確かめていない。
ブランチや作成元に、git が断る文字（空白、`..`、`~`、`:` など）や、`-` で始まる名前があると、worktree を作る前に断る。
選んだものは項目ごとにメモリにだけ置く（保存しない）。

### 渡す

指示は、書いたまま渡る。Claude は要約しない。
右下の矢印のアイコン（Cmd+Enter でもよい）を押すと、Claude がカードの内容を箇条書きに要約し、新しいセッションが起動する。
要約を作っているあいだと渡しているあいだは押せない。指示が空のときと、プロジェクトを選んでいないときも押せない。
Orca に渡る文は、書いた指示、添付したファイルのパス、内容の要約、元の内容の引用の順。
カードの × で外すと、要約も引用もなく、指示だけが渡る。
カードがあるのに Claude が使えないときは、押せない（カードを外せば渡せる）。
指示の欄にも、ファイルを貼り付けるか、ドロップして添付できる（添付したファイルは欄の上に並び、× で外せる。画像はサムネイル、画像でないファイルは名前で出る）。
ファイルは渡す前に、送り先の worktree の `.orca/drops/` に置かれ、そのパスが指示のあとに加わる（Claude には送らない）。
使えるファイルと接続先は、ターミナルと同じ。

### 渡したあと

渡すと、ペインはそのセッションのターミナルに変わる。
上には、「リポジトリ ・ ブランチ」と状態、「Orca の画面で開く」のボタン、閉じるアイコンが並ぶ。
ターミナルにはそのまま打ち込め、ファイルも貼り付けかドロップで添付できる。Claude の質問には、ここで答える。
このマシンのセッションは、画面を読んで写す（色は出ず、全画面のプログラムは近似になる）。
保存したサーバーのセッションも出す。
閉じるアイコンを押すまでは、別の項目に移って戻っても、同じセッションを出す。閉じると、次は渡す画面に戻る。
Orca からなくなったセッションは「終了」と出て、ターミナルは止まる。
