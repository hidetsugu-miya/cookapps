# Orca

Orca は、エージェントを動かすデスクトップアプリです。

## 一覧

サイドメニューの Orca のアイコンで、Orca のプロジェクトを一覧する（状態のアイコンとセッション数を出し、SSH の接続先も並べる）。
作業中のセッションがあるプロジェクトは上に集め、入った順に固定する（作業が進んでも入れ替わらず、新しく作業が始まったものが先頭に入る）。その下に、セッションはあるが作業中ではないプロジェクトを並べ、セッションの無いプロジェクトはその下に並べる（どちらも最近動いた順）。
プロジェクトの行の矢印で、そのプロジェクトのセッションの行を開閉する（行は 1 段字下げして並ぶ。複数のプロジェクトを同時に開ける）。
最初は作業中のプロジェクトがすべて開いていて、閉じたプロジェクトも、新しいセッションが作業を始めると開き直す。
行を押すとそのタブを選び、右のペインでタブを押すと、その行が選ばれる。
一覧の上の検索欄に打った文字で、プロジェクトと SSH の接続先を名前で絞り込む（Orca 画面のどこにいても Cmd+J で検索欄に移れ、↓↑で行を動き、Enter で選び、Escape で消す）。
ベルで「入力待ち」「作業中」「完了」に分けた Claude のセッションの一覧に切り替える（見出しを押すと、その群を開閉できる。最初はすべて開いている。入力待ちと、完了や中断で止まって未確認のセッションの件数はサイドメニューのアイコンにも出す。作業中のセッションがある間は、アイコンが黄色になってゆっくり明滅する。一覧の幅はドラッグで変えられる）。

### 接続先

接続先は左ペインの下端で、このマシンか Orca に保存したサーバーから選ぶ（`orca` CLI と Orca のペアリング情報を使う。アプリは履歴を保存しない）。

## セッション

右のペインではプロジェクトのセッションをタブで切り替え、タブから閉じられる。
どのタブもターミナルで、Claude のセッションにもそのまま打ち込める。
右のペインのタブ列の右端の＋から、「Claude を起動」か「ターミナルを開く」を選ぶと、左ペインで選んでいるプロジェクト（か SSH の接続先）の worktree で始める。
worktree が 2 つ以上あるときは、選ぶ画面を出す。
始めたセッションとターミナルは一覧に現れるとタブで開く。

## ターミナル

保存したサーバーが接続先のときは、Orca が送るターミナルの出力を描く（色も出る）。
ターミナルはいつもペインの大きさに合わせて描く。
このマシンが接続先のときは、Orca が出力を送れないので、画面を毎秒読んで写す。
色は出ず、`claude` のような全画面のプログラムは近似になる。

### コピー

`claude` のようにマウスを使うプログラムでは、ドラッグで選んだ文字列をプログラムが送り、それがクリップボードに入る。
入らなかったときは、⌘C か「編集 > コピー」で入る。
Option を押しながらドラッグすると、プログラムではなくターミナル側で文字を選べる。

### ファイル

ターミナルには、ファイルを貼り付けるか、ドロップできる。画像でも、画像でないファイルでもよい（Finder でコピーしたファイルも貼り付けられる）。
ファイルは、そのセッションの worktree の `.orca/drops/` に、元の名前で置かれる。同じ名前があるときは、`名前 copy.拡張子` のように名前を変える。
置いたファイルのパスがターミナルに入力される（Claude がそのパスからファイルを読む）。画像のパスは貼り付けとして入力し、画像でないファイルのパスは打ち込む。
このマシンの worktree と、保存したサーバーの worktree で使える。SSH の接続先の worktree と、ファイルを書く権限のないペアリングでは使えない。
20 MiB まで置け、置いたファイルは自動では消えない。読めないファイル（フォルダなど）を含むときは、どれも置かない。

### ターミナルの配色

設定の「Orca」タブの「ターミナルの配色」で、ターミナルの配色を選ぶ。
「外観」で「システムに合わせる」「ライト」「ダーク」から選ぶ。
「ライト」か「ダーク」にすると、システムの外観に関係なく、そのテーマで描く。
ライトとダークのテーマは別々に選ぶ。
「システムに合わせる」のときは、システムの外観に合わせて切り替わる（Orca の外観の設定には合わせない）。
選べるのは Orca の組み込みのテーマで、色の見本が出る。
初めての選択は、この Mac の Orca の設定から取る（読めたときの 1 回だけ。Orca の設定は読むだけで、書き換えない）。
Orca に足したテーマや、組み込みにないテーマのときは、ライトは Builtin Tango Light、ダークは Ghostty Default Style Dark になる。
Ghostty の設定を取り込んでいても、色はここで選んだテーマを使う。
フォントは、設定の「フォント」タブでターミナルの書体を選んだときはそれを使い、「Ghostty の設定に従う」のままなら Ghostty の設定を使う（キーは Ghostty の設定のまま）。

## ファイルとエディタ

「ファイル欄」のボタンで、選んでいるタブの worktree のファイルを木で出す。
タブが無いときは、左の一覧で選んでいるプロジェクトの主の worktree（リポジトリ本体のフォルダ）を出す。
ファイルやフォルダの行を右クリックすると、「パスのコピー」と「相対パスをコピー」のメニューが出る。
ファイルの行のメニューには「ダウンロード」もある。押すと保存ダイアログが出て、選んだ場所にそのファイルをこの Mac へ保存する（保存した環境のファイルも同じ）。
ボタンは、ファイル欄を隠しているときは右上のペインのタブ列の右端に、出しているときはファイル欄の上の段の右端にある。
フォルダは押すと開き、中身を Orca から読む。もう一度押すと閉じる。
「ファイルを読み直す」で、ルートと開いているフォルダを読み直す。
git が無視するファイルとフォルダは、薄い斜体で出す。
ファイルをダブルクリックする（か、選んで Enter を押す）と、タブで開いて、その場で書き換えられる。
同じファイルをもう一度開くと、そのタブを選ぶ。
入力が止まって、設定の「Orca」タブの「エディタ」の「自動保存までの時間」（100 から 3000 ms、初めは 1000 ms）が過ぎると、自動で保存する。保存のボタンはない。
エディタの書体と大きさは、設定の「フォント」タブで選ぶ。
未保存の入力があるタブには、印が付く。
タブを閉じるときと、ウィンドウを閉じるときも、入力があれば保存する。
開く前に読んだ内容とディスクのファイルが違っていたら（別のところで書き換えられたか、消えたとき）、上書きしない。
そのときは見出しに理由が出て、入力は画面に残り、そのタブはもう保存しない。
ファイルを閉じて開き直すと、ディスクの内容を読み直す。

開けるのは、384 KiB までの UTF-8 のテキストで、改行が LF だけか、全部の行が CRLF のファイルだけ。
バイナリのファイル、UTF-8 でないファイル、改行が混ざっているファイルは、開けない。
このマシンの worktree と、保存したサーバーの worktree で使える。SSH の接続先の worktree では使えない。

## Orca に渡す

開いているメール、Slack のスレッド、Todo の内容を、その画面の右ペインから Orca に渡す。
送り先（worktree を選んだ新しいセッションか、動いているセッション）を選び、渡す内容を確かめ、指示を書いて自分で送る。
起動後は同じペインで履歴を読み、追加の指示を送れる。
ツールの実行は 1 行に畳まれ、押すと開く。
エージェントの質問は畳まず、選択肢と回答も出す。
回答待ちの質問は箱の中で選択肢を選び、「回答を送る」で答えられる。
渡した内容は履歴では 1 行に畳まれ、押すと開く。
指示の欄にも、ファイルを貼り付けるか、ドロップして添付できる（添付したファイルは欄の上に並び、× で外せる。画像はサムネイル、画像でないファイルは名前で出る）。
ファイルは送る前に、送り先の worktree の `.orca/drops/` に置かれ、そのパスが指示に加わる。
使えるファイルと接続先は、ターミナルと同じ。
