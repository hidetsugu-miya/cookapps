# cookapps

cookapps は、個人向けのデスクトップ Gmail クライアントです。
複数の Gmail アカウントの受信トレイを 1 つの一覧で表示します。未読は上、既読は下に分けて並べ、未読の行の上の見出しの右端にある「すべて既読にする」で、一覧に出ている未読のスレッドをまとめて既読にできます。
スレッドの本文を読み、アーカイブ、ゴミ箱への移動、既読・未読の切り替えができます。
未読のスレッドを開くと、既読になります。
本文のリンクを押すと、既定のブラウザで開きます。
約 10 秒ごとに Gmail と同期するので、新着や他の端末での変更が自動で反映されます。
また、Google Calendar の予定を、全アカウント分まとめて週表示で閲覧できます。
予定を押すと、日時、Meet のリンク、場所、説明、参加者の人数などの詳細をその横に表示します。
週の始まりの曜日は、設定の「カレンダー」タブで選べます。
Todoist に接続すると、タスクをプロジェクト別と「今日」の一覧で表示し、完了・追加・編集できます。タスクのラベルも付け外しでき、新しいラベルも作れます。
タスクの詳細では、Todoist のコメントを読み、コメントの追加とファイルの添付もできます。
受信トレイのスレッドから「Todo にする」でタスクを作ることもできます。
Claude が使えるときは、Todo 画面の右側の Claude のペインにやりたいことを伝えると、タスクの案（名前、日付、プロジェクト）をカードで出します。カードで案を直して「追加」を押すと、そのとき初めて Todoist にタスクを作り、「却下」ならカードを閉じます。
Todoist に接続できないときは、前回取得した内容を表示します。
サイドメニューには、未読の件数と今日の Todo の件数を表示します。
設定の「Slack」タブで Slack のワークスペースを追加すると、開いているメールの最新のメッセージを、貼るときに選んだチャンネルやスレッドに貼れます。
サイドメニューの Slack のアイコンでは、サイドメニューの「未読メッセージ」と「ウォッチ」で切り替えて、参加しているチャンネルのメッセージを、「未読」（チャンネルごとにまとめて、チャンネルごとに新しい 10 件まで）と、自分で選んだスレッドを残す「ウォッチ」の一覧で見て、スレッドを開き、返信できます。サイドメニューには、ワークスペースごとに参加しているチャンネルが名前順に並び、押すとそのチャンネルの最新の 50 件の履歴を開いて、その下の欄からチャンネルに投稿できます（履歴を開いても既読にはなりません）。既読になったメッセージは、ウォッチしていなければ一覧から消えます。各チャンネルの見出しの「既読に設定」で、そのチャンネルの既読位置を、一覧に出ていない分も含めて最新の未読まで進め、そのチャンネルのスレッドの未読の返信も既読にできます。メッセージを開くと、Slack 側のそのチャンネルも既読になります。サイドメニューの Slack のアイコンには、未読の数が出ます（20 を超えると「20+」）。新しい未読のメッセージが見つかると、ウィンドウの右下にカードを出し、そこから既読にする、ウォッチする、スレッドを開くができます。サイドメニューのチャンネルにマウスを乗せると出るボタンで、そのチャンネルを一覧に出さないようにでき、設定の「Slack」タブで戻せます。ボットやアプリの投稿のブロックと添付のカードも、一覧とスレッドの詳細に出ます（画像は、スレッドの詳細で「画像を表示」を押したときだけ取得します）。スレッドに自分以外の未読の返信があると、一覧の行の下に開閉できる「未読の返信」を出します（ここで読んでも Slack 側のスレッドの未読は消えません）。スレッドの詳細では、メッセージの Slack の書式（太字、斜体、取り消し線、コード、コードブロック、引用）を、その見た目で出します。返信の文章の校正、スレッドの要約、質問への回答、返信案の作成は、Claude Code で頼めます（頼みを送ると、返信欄の文章とスレッドのメッセージが Anthropic へ渡ります）。
サイドメニューは、開いている画面に合わせて、その機能のアカウントを、アイコンの下に出します。メールとカレンダーでは Google のアカウント、Slack ではワークスペースです。
新しい版が出ると、設定のアイコンと、設定の「アップデート」タブに赤い点が付きます。右下に出るポップアップの「更新して再起動」から、ダウンロードと入れ替えをまとめて行えます（macOS の Apple Silicon のみ）。「あとで」で閉じると、同じ版では、アプリを終了するまで出ません。
設定の「アップデート」タブでは、いま動いている版を確かめられ、更新の方法を「手動」と「自動」から選べます。自動を選ぶと、新しい版を裏で入れ替えておき、ポップアップの「再起動」を押したときに再起動します。再起動を待つあいだも確認を続け、さらに新しい版が出ていれば、それを入れ替え直します。このタブにも、新しい版があるときは同じボタンが出ます。
設定は「Google」「カレンダー」「Todoist」「Slack」「Claude」「Orca」「フォント」「アップデート」の 8 つのタブに分かれています。
「フォント」のタブでは、アプリ全体と、メール、カレンダー、Slack、Todo、Orca の画面ごとに、書体と大きさを選べます。コードなどの等幅の文字の書体も選べます。
「Claude」のタブでは、Claude Code をサブスクリプションと Anthropic の API キーのどちらで使うかを選べます。
MCP サーバーを設定すると、Claude Code から受信トレイと予定を扱えます。
