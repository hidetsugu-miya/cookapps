# プライバシーポリシー

最終更新日: 2026年10月31日

cookapps（以下「本アプリ」）は、利用者自身のパソコン（macOS または Windows）上で動くデスクトップ Gmail クライアントです。
本アプリが Google アカウントのデータをどう扱うかを説明します。

## 取得するデータ

本アプリは、利用者の同意を得て、Gmail API と Google Calendar API から次のデータを取得します。

- 受信トレイのスレッドの一覧（差出人、件名、日時、抜粋、既読状態）
- 利用者が開いたスレッドのメッセージ本文
- ログインした各アカウントのメールアドレス
- 受信トレイを最新に保つための、メールボックスの変更履歴（history）。約 10 秒ごとに確認します
- 利用者のカレンダーの一覧（表示の対象になっているカレンダーのIDと色）
- 表示中の週の予定（タイトル、開始・終了の日時、利用者自身の出欠の状態）。カレンダーを開いたとき、週を移したとき、表示中は 5 分ごとに取得します
- Claude との連携（`cookapps-mcp`）を利用者が設定した場合は、MCP クライアントからの呼び出しに応じて、上と同じ種類のデータを取得します。予定は、呼び出しで指定された期間のものを取得します
- Claude との連携（`cookapps-mcp`）を利用者が設定した場合は、MCP クライアントからの呼び出しに応じて、上と同じ種類のデータを取得します。予定は、呼び出しで指定された期間のものを取得します

要求するスコープは次の 2 つです。

- `https://www.googleapis.com/auth/gmail.modify`
- `https://www.googleapis.com/auth/calendar.readonly`（予定を閲覧するためだけに使い、予定の作成・編集・削除はしません）

利用者が Todoist に接続した場合は、Todoist のサーバーから、タスク（名前、説明、期限、優先度、サブタスク）とプロジェクトも取得します。
アプリを起動したとき、Todo 画面を開いたとき、ウィンドウに戻ったとき、約 10 秒ごと（前回からの変更だけ）、タスクを操作したあとに取得します。
サイドメニューの Todo に、今日の件数を表示するためです。

## データの使い方

取得したデータは、本アプリの画面に表示するためだけに使います。
例外は、利用者が「Todo にする」を押したスレッドの件名と、アカウントのメールアドレスを含む Gmail の URL を Todoist に送ることです。
約 10 秒ごとに変更履歴を確認し、変わったスレッドの一覧用の情報（差出人、件名、日時、抜粋、既読状態）だけを取り直して画面に反映します。
利用者の操作に応じて、スレッドのゴミ箱への移動と、受信トレイからの除外（アーカイブ）を Gmail API に依頼します。
利用者が「元に戻す」を押したときは、その取り消し（ゴミ箱からの復元、受信トレイへの戻し）も依頼します。
また、スレッドの既読・未読の切り替えも Gmail API に依頼します。
未読のスレッドを開いたときも、既読にするよう依頼します。
カレンダーの予定は、画面に表示するためだけに使います。
`cookapps-mcp` を設定した場合は、取得したデータを、利用者が設定した MCP クライアント（Claude Code など）へ渡します。
スレッドのゴミ箱への移動、アーカイブ、既読・未読の切り替えも、そのクライアントからの呼び出しに応じて Gmail API に依頼します。
メールの送信、削除（ゴミ箱を経由しない削除）、設定の変更はしません。

## 保存

ログインの維持に使うリフレッシュトークンは、アカウントごとに OS の資格情報の保管場所（macOS ではキーチェーン、Windows では資格情報マネージャー）へ保存します。
ログインしたアカウントのメールアドレスの一覧は、本アプリの設定フォルダに保存します。
「画像を表示」を押した送信者のメールアドレスの一覧も、設定フォルダに保存します。
起動直後や画面を開いた直後に、取得を待たずに前回の内容を表示するため、受信トレイのスレッドの一覧（差出人、件名、日時、抜粋、既読状態）と、表示した週のカレンダーの予定（最大 10 週）を設定フォルダのファイルに保存します。
受信トレイは、すべてのアカウントを全件読み込めたとき、カレンダーは、すべてのアカウントとカレンダーを取得できた週だけ、新しい内容に書き換えます。
アカウントを削除すると、この 2 つのファイルも消えます。
Todoist に接続している場合は、同じ目的と、取得に失敗したときの表示のために、Todoist のタスクとプロジェクトを設定フォルダのファイルに保存します。
Todoist の接続を解除すると、このファイルも消えます。
メールの本文は保存せず、本アプリを終了すると消えます（`cookapps-mcp` も同じで、上のファイルも書きません）。

## 第三者への提供

本アプリには開発者が運営するサーバーがなく、取得したデータを開発者へ送信しません。
第三者へ渡すのは、利用者が `cookapps-mcp` を MCP クライアントに設定し、そのクライアントが呼び出した場合と、利用者が Todoist に接続して「Todo にする」を押した場合（スレッドの件名と、アカウントのメールアドレスを含む Gmail の URL）と、利用者が Slack に接続して「貼る」を押した場合（スレッドの最新のメッセージの件名、差出人、日時、本文のテキストと、ひとこと）と、利用者が Slack のメッセージの URL を貼って「要約する」を押した場合（そのメッセージの本文のテキスト。Claude Code を通じて Anthropic へ）と、利用者がメールの詳細画面で「AI 要約」を押した場合（そのスレッドの件名と、各メッセージの差出人、日時、本文のテキスト。Claude Code を通じて Anthropic へ）だけです。
渡したデータは、そのクライアントと提供元（Claude であれば Anthropic）のポリシーに従って扱われます。
本アプリが通信するのは Google のサーバーと、利用者が接続した場合の Todoist のサーバー、利用者が Slack のトークンを設定した場合の Slack のサーバー、利用者が「要約する」または「AI 要約」を押した場合の Claude Code を通じた Anthropic のサーバー、利用者が「画像を表示」を押した送信者のメッセージの画像の送り主のサーバー、新しい版を確かめる GitHub のサーバー（GitHub Releases）だけです。
HTML 形式のメールに含まれる画像は、既定では読み込みません。
利用者がメッセージの「画像を表示」を押したときだけ、そのメッセージの画像を送り主のサーバーから取得します（https のみ）。
このとき、そのメッセージの送信者のメールアドレスを覚え、以後はその送信者のメッセージを開いたときに、画像を自動で取得します。
覚えた送信者は、メッセージの「この送信者の画像を自動で表示しない」で外せます。
自動で取得するのは、Gmail が付けた認証結果（Authentication-Results）が DMARC 合格、または From のドメインと一致する DKIM 署名の合格のメッセージだけです。
そうでないメッセージは、覚えた送信者のものでも、「画像を表示」を押すまで取得しません。
このとき、取得先のサーバーに利用者の IP アドレスが伝わり、メールが開かれたことが送り主に知られることがあります。
スタイルシートなど、画像以外の外部のものは読み込みません。
メール本文のリンク（http と https のみ）は、利用者が押したときだけ、既定のブラウザで開きます。
本アプリ自身はそのリンクの先と通信しません。

## Todoist との連携

利用者が Todoist の個人 API トークンを入力した場合に限り、本アプリは Todoist のサーバーと通信して、タスクとプロジェクトを表示・操作します。
「Todo にする」を押したスレッドの件名と、アカウントのメールアドレスを含む Gmail の URL を Todoist に送り、トークンは OS の資格情報の保管場所に保存して、Todo 画面の「Todoist の接続を解除」で消せます。
取得したタスクとプロジェクトは、起動直後や Todo 画面を開いた直後と、Todoist に接続できないときに前回の内容を表示するため、設定フォルダに保存し、接続を解除すると消します。

## Slack との連携

利用者が Slack の User OAuth Token を設定に入力した場合に限り、本アプリは Slack のサーバー（slack.com）と通信します。
トークンはワークスペースごとにいくつでも入力でき、入力したときに Slack の `auth.test` で確かめ、設定画面を開いたときにも確かめます。
「Slack に貼る」を開くと、選んだワークスペースの参加しているチャンネルの名前を Slack から取得し、本アプリを閉じるまでメモリにだけ覚えます。
Slack のリンクを入力したときは、そのチャンネルの名前を Slack から取得します。
トークンは OS の資格情報の保管場所にワークスペースごとに保存し、設定画面の「接続を解除」で、そのワークスペースのトークンを Slack に取り消して消せます。画面には表示しません。
メールの内容を Slack に送るのは、利用者がメールの詳細画面で「Slack に貼る」の「貼る」を押したときだけです。
送るのは、その画面のスレッドの最新のメッセージの件名、差出人、日時、本文のテキスト（3,000 文字まで）と、利用者が入力したひとことです。
ワークスペースの ID、名前、ユーザー名、URL は、設定フォルダの `slack-workspaces.json` に保存します。
貼れた宛先（ワークスペースの ID、チャンネル ID、チャンネル名、スレッドの識別子）は、新しい順に 8 件まで、同じ場所の `slack-recent.json` に保存します。メールの内容は保存しません。
送ったメッセージは、利用者の Slack ワークスペースと Slack のポリシーに従って扱われます。

## Claude Code による要約

利用者が Todo 画面の追加欄に Slack のメッセージの URL を貼り、「要約する」を押したときだけ、本アプリはそのメッセージを Slack から読み、利用者のパソコンにある Claude Code（`claude`）を起動して要約します。
Claude Code に渡すのは、そのメッセージの本文のテキスト（スレッドの返信であれば、スレッドの最初のメッセージのテキストも。合わせて 10,000 文字まで）で、Claude Code を通じて Anthropic のサーバーへ送られます。
利用者がメールの詳細画面で「AI 要約」を押したときだけ、本アプリは同じように Claude Code を起動して、そのスレッドを要約します。
Claude Code に渡すのは、そのスレッドの件名と、各メッセージの差出人、日時、本文のテキスト（新しいメッセージから順に、合わせて 10,000 文字まで）で、Claude Code を通じて Anthropic のサーバーへ送られます。
メールを開いただけでは渡しません。
メールの要約は、件名の下のカードに表示するだけで、保存せず、Todoist など他へも送りません。本アプリを終了すると消えます。
送ったデータは、Anthropic のポリシーと、利用者の Claude のアカウントの設定に従って扱われます。
どちらの要約でも、モデルにはファイルを読み書きする道具も MCP サーバーも渡しません。
Slack のメッセージの要約の結果は、タスクの名前と説明として Todoist に送ります。
設定の Claude の欄とサイドメニューに状態（ログイン中のメールアドレスとプラン、Claude Code の版）を出すため、`claude auth status` と `claude --version` を実行します。メッセージの内容は渡しません。

## アップデートの確認

本アプリは、起動したときと 5 分ごとに、GitHub Releases（github.com）の `latest.json` を取得して、新しい版があるかを確かめます。
このとき GitHub には、利用者の IP アドレスなど通常の通信の情報が伝わります。メールなど利用者のデータは送りません。
自動で入れ替えられるのは macOS（Apple Silicon）版だけです。
新しい版があるときの動きは、設定の「アップデート」で選べます。
「手動」では、サイドメニューの更新ボタンを押したときに限り、GitHub Releases から新しい版をダウンロードし、署名を確かめて入れ替えます。
「自動」（初期値）では、新しい版が見つかり次第、裏でダウンロードし、署名を確かめて入れ替えます。
どちらでも、アプリの再起動は、利用者がサイドメニューの更新ボタンを押したときだけ行います。

## Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用と移転は、[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)（Limited Use の要件を含む）に従います。

## アクセスの取り消し

本アプリからアカウントを削除すると、本アプリは Google にそのアカウントのアクセス権の取り消しを依頼し、資格情報の保管場所のリフレッシュトークンと設定フォルダのメールアドレスも消します。
取り消しの依頼に失敗しても、本アプリ側の削除は続けます。
Gmail のメールそのものは消えません。

本アプリへのアクセス権は、Google アカウントの「[サードパーティ製のアプリとサービス](https://myaccount.google.com/connections)」からいつでも取り消せます。
保存したリフレッシュトークンは、macOS ではキーチェーンアクセスで「jp.mysis.cookapps」の項目を、Windows では資格情報マネージャーの「Windows 資格情報」で名前が「jp.mysis.cookapps」で終わる項目を削除すると消せます。
Todoist のトークンは、Todo 画面の「Todoist の接続を解除」か、同じ場所で「jp.mysis.cookapps.todoist」の項目（Windows では名前がそれで終わる項目）を削除すると消せます。
Slack のトークンは、設定画面の「接続を解除」か、同じ場所で「jp.mysis.cookapps.slack」の項目（ワークスペースごと。Windows では名前がそれで終わる項目）を削除すると消せます。
キーチェーンアクセスや資格情報マネージャーで消した場合は、設定フォルダの `todoist-cache.json`（最後に取得したタスクの控え）が残るので、手で消してください。
v0.14.6 以前（旧名 cookup）の本アプリを使っていた場合は、同じ場所の「jp.mysis.cookup」で始まる項目と、旧設定フォルダ（macOS では `~/Library/Application Support/jp.mysis.cookup`、Windows では `%APPDATA%\jp.mysis.cookup`）も手で消してください。旧名の項目のアクセス権は、上の「サードパーティ製のアプリとサービス」から取り消せます。
