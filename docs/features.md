# 機能

機能の一覧です。

- 複数の Gmail アカウントを追加し、全アカウントの受信トレイを 1 つの一覧で表示する（未読を上、既読を下に分け、それぞれ新しい順）。アカウントの追加と、各アカウントの状態と未読の件数の確認は、設定の「Google」タブで行う
- スレッドを開いて本文を表示する（日本語の文字コードと HTML メールに対応。メールに埋め込まれた画像は表示する。外部の画像は既定では読み込まず、メッセージの「画像を表示」を押したときだけ取得し、その送信者のアドレスを覚えて、以後はその送信者のメッセージの画像を自動で表示する。自動で取得するのは、Gmail が付けた認証結果（Authentication-Results）が DMARC 合格、または From のドメインと一致する DKIM 署名の合格のメッセージだけで、そうでないメッセージは覚えた送信者でも「画像を表示」を押すまで取得しない。行を押すとすぐ詳細の画面に移り、件名と送り主を出して、本文が届くまで「読み込んでいます…」を出す（届くまで、戻る以外のボタンは押せない）。未読のスレッドを開くと既読になる。本文のリンクを押すと、既定のブラウザで開く。複数のメッセージがあるスレッドでは、新しい順に並べ、最新のメッセージだけを一番上で開き、古いものは 1 行に畳んで、押すと開く）
- スレッドをアーカイブする・ゴミ箱へ移動する（詳細画面のボタン、または一覧の行にマウスを乗せると出るボタン）。直前の 1 件は Cmd+Z（Windows では Ctrl+Z）かお知らせの「元に戻す」で戻せる
- 一覧のチェックボックスで、スレッドを既読・未読にする（未読の行には緑の点が付く）。一覧の上のヘッダーの「すべて既読にする」で、一覧に出ている未読のスレッドをまとめて既読にでき（最大 4 件ずつ送る。失敗した行は未読に戻してエラーを出す）、通知の「元に戻す」で未読に戻せる
- サイドメニューのアカウントのアイコンから、そのアカウントを cookapps から削除する（Google 側のアクセス権も取り消す。Gmail のメールは消えない）
- 約 10 秒ごとに受信トレイを Gmail と同期し、新着や他の端末での既読化・アーカイブを自動で反映する。一覧の上のヘッダーに「受信トレイ」と「すべて既読にする」が付き（スクロールしても残る）。最初の読み込みが返るまでは「読み込んでいます…」、スレッドが 0 件のときは「受信トレイにスレッドはありません」を出す。読み込みに失敗したときは、一覧の上に「読み込めませんでした: …。自動でも読み直します」と「再読み込み」のボタンを出し（前の一覧があるときは一覧を残す。別の画面へ移って戻っても残り、次の読み込みが成功すると消える）、前の読み込みから 60 秒たつと自動で読み直し、続けて失敗するたびに間隔を倍にする（最長 5 分）。スレッドを開いている間に再ログインが必要になったときは、次の同期で一覧を読み直す
- 同期で新着のメールが見つかると、ウィンドウの右下にカードを出す（差出人と件名、ゴミ箱へ移動・アーカイブ・詳細を開くのボタン。詳細を開くは他の画面からでもそのスレッドに移る。カードは最大 3 枚で、10 秒で消える（マウスやフォーカスが乗っている間は残る）。起動時の読み込みでは出さず、OS の通知も使わない）
- 未読のスレッドの件数を、サイドメニューの受信トレイのボタンに表示する（0 件のときは消える。macOS の Dock のアイコンのバッジには、この件数と、Todo の期限が来た未完了の件数の合計を表示する。期限の時刻が過ぎるとウィンドウが隠れていても自動で増える）
- 設定は「Google」「カレンダー」「Todoist」「Slack」「Claude」「Orca」「アップデート」の 7 つのタブに分かれ、開くと Google のタブが出る。「設定」の見出しとタブは、カードをスクロールしても上に残る
- 全アカウントの Google Calendar の予定を、1 つの週表示にまとめて表示する（閲覧のみ。サイドメニューのカレンダーのアイコンで開く）。自分が未定と答えた予定は斜線、まだ返信していない予定は色を反転して表示する。週の始まりの曜日は、設定の「カレンダー」タブで日曜から土曜の中から選べる（初期値は日曜）
- カレンダーの予定を押すと、その横に詳細を出す（日時、Meet に参加するボタンと URL のコピー、場所、説明、参加者の人数と承諾した人数、カレンダー名とアカウント、自分の回答）。詳細は週の取得と一緒に取り、押したときの通信はない。別の予定を押すと切り替わり、同じ予定をもう一度押すか、✕・Escape・外側のクリックで閉じる
- Todoist のタスクを、プロジェクト別（Todoist と同じ親子関係でネストする）と「今日」の一覧で表示し、完了・追加・編集（説明とサブタスクを含む）する。説明は Markdown で表示し、10 行を超える説明は 10 行目で折りたたんで「… 続きを表示（残り n 行）」で全文を出し、押すと編集して「保存」で登録する。「今日」で追加した、日付の無いタスクは期限が今日になる。期限は月のカレンダーから選べる。サブタスクは一覧の行の左のトグルで開閉する。詳細画面の右にプロジェクトと日付を出し、日付はマウスを乗せると出る × で消せる。サブタスクの詳細には、名前の上に直接の親タスクを出し、押すと親を開く（左の丸いチェックで、親タスクを完了にできる）。詳細画面の右の「ラベル」には、タスクのラベルを色の点と名前で並べ、× で外せる。＋で出る欄で、ラベルを絞り込んでタスクに付け外しし、無い名前は新しく作って付けられる。詳細画面の右上の「…」メニューから、タスクのリンクや説明（Markdown のまま）をコピーしたり、タスクを削除したりできる（削除は二度押す）。説明は、文字を選んでコピーでき（選んでも編集は始まらない）、マウスを乗せると右上に出るコピーのアイコンでもコピーできる。一覧の行にマウスを乗せると、詳細を開かずに名前・期限・プロジェクトを変えられ、行の左端をドラッグして、左のプロジェクトへ移したり、別のタスクの行に落としてそのタスクのサブタスクにしたりすることもできる（落とせる行は枠で示す。自分自身、自分のサブタスク、今の親には落とせない）。サブタスクは、行にマウスを乗せると出る「親タスクから外す」ボタンか、今いるプロジェクトへのドラッグで、親から外して単独のタスクに戻せる。詳細画面のサブタスクの行（未完了のもの）も、一覧の行と同じく、マウスを乗せると出るボタンとドラッグで、別のプロジェクトへ移す、親から外す、詳細のほかのサブタスクの下へ入れる、ができる。詳細画面の下には、タスクのコメント（投稿者、日時、Markdown の本文、添付ファイル）を一覧し、コメントの追加と、ファイル 1 つ（100 MB まで）の添付ができる（⌘Enter か送信ボタンで送り、Enter は改行になる）。受信トレイのスレッドから「Todo にする」でタスクを作る。Todoist に接続できないときは、前回取得した内容を表示する（Todoist の個人 API トークンを使う。サイドメニューの Todo のアイコンで開き、期限（日付と時刻。時刻の無い日付は 0 時）が来た未完了の件数をそのアイコンに表示する。期限の無いタスクは数えない。接続の状態の確認と解除は、設定の「Todoist」タブで行う。一覧の見出しの Claude のアイコンから、要約プロンプトの画面を開ける）
- メールを Slack に貼る（詳細画面の「Slack に貼る」で専用の画面が開き、スレッドの最新のメッセージの件名・差出人・日時・本文が編集欄に入る。編集欄の文章を直して、貼るときに選んだチャンネルかスレッドに投稿する。「元の内容に戻す」で最初の文に戻せる。宛先は、最近使った先、参加しているチャンネルの検索、Slack のリンクから選ぶ。複数のワークスペースを持て、トークンはサイドメニューの設定で追加する）
- サイドメニューは、開いている画面に合わせて、その機能のアカウントを、アイコンの下に並べる（メールとカレンダーでは Google のアカウントをカレンダーのアイコンの下に、Slack ではワークスペースを Slack のアイコンの下に出す。Todo と設定では出さない。ワークスペースの絵は、そのワークスペースでの自分のアイコン）
- サイドメニューの Slack のアイコンで、参加しているパブリックとプライベートのチャンネルのメッセージを、全ワークスペース分まとめて、「未読」（最大 20 件。最初は 10 件で、残りはボタンで出す）と「ウォッチ」の 2 段で、新しい順に一覧する（DM とグループ DM は出さない。送信者のアイコンと名前、チャンネル、本文（ふつうの投稿は 2 行まで、ボットの投稿は項目ごとに書式つきで）、返信の件数、日時を出す。新着は自動で読み直す。設定の「Slack」タブの「リアルタイム更新」でワークスペースごとに App-Level Token を登録すると、Socket Mode でつなぎ、投稿・返信・変更・削除を約 1 秒で一覧と未読の件数に出す）。未読のメッセージは、既読になると一覧から消える。一覧の上のヘッダーに「Slack」の見出しと、「すべて既読にする」（未読のあるチャンネルごとに Slack の既読位置を最新のメッセージへ進める。戻せないので 2 回押す）と、「一覧に出さないチャンネル」を開く設定のアイコンが付く。未読の件数は Slack のアイコンにも出す（20 件を超えると `20+`。0 件のときは消える）。行にマウスを乗せると出るアイコンで、そのチャンネルを一覧に出さないようにでき、設定の「Slack」タブで戻せる。その隣のしおりで、そのスレッドをウォッチでき、ウォッチしたスレッドは外すまで「ウォッチ」の段に残り、新しい返信があると「新しい返信 N 件」を出す
- 未読の返信があるスレッドは未読の段に出し、行の下の「未読の返信 N 件」で返信を開閉する（最初は開いている。ここで読んでも Slack 側のスレッドの未読は消えない）
- 行にマウスを乗せると出るチェックで、スレッドを開かずにその行を既読にする（Slack の既読位置はチャンネルに 1 つなので、同じチャンネルのそれより古い行も既読になる）
- 一覧の行を押すと、そのスレッドの詳細が開く（メッセージを古い順に、送信者のアイコン、名前、時刻、本文で出す。本文の Slack の書式（`*太字*`、`_斜体_`、`~取り消し~`、`` `コード` ``、``` で囲んだコードブロック、`>` で始まる引用）は、その見た目で出す。添付の画像はサムネイルで、画像でないファイルは名前の札で出し、押すと Slack で開く。ボットやアプリの投稿のブロックと添付のカードも出す（URL 付きのボタンは既定のブラウザで開く。画像は「画像を表示」を押したときだけ取得する）。「Slack で開く」と、「Todo にする」（Claude Code と Todoist が使えるときだけ。要約のカードは「[Slack のメッセージを要約して Todo にする](slack.md#slack-のメッセージを要約して-todo-にする)」と同じ）がある）
- スレッドの詳細の下の欄から、スレッドに返信できる（Enter は改行、⌘Enter（Windows は Ctrl+Enter）か「返信する」で投稿する。書きかけの文章と Claude との会話は、アプリを終了するまでスレッドごとに残る）
- 詳細の右側の Claude 欄で、スレッドのことを Claude に相談できる（返信の文章の校正、スレッドの要約、質問への回答、返信案の作成。送るのはスレッドのメッセージと返信欄の文章と会話と依頼。変更案は差分で出て、「却下」「コピー」「適用」ができ、適用しても投稿はしない。頼みを書く欄の下で、この相談のモデルと effort を切り替えられる）
- Slack に貼る画面の右側で、Claude Code と文章を校正できる（「校正する」を押すか、依頼を書いて送る。変更案は差分で出て、「適用」で編集欄に入り、「却下」で捨てる。適用しても投稿はしない。Claude Code を使えるときだけ。区切りをドラッグするか左右の矢印キーで、Claude 側の幅を変えられる）
- メールの詳細画面の「AI 要約」アイコンを押すと、Claude Code がスレッドを要約し、要点の短い箇条書きを件名の下のカードに出す（Claude Code を使えるときだけ）
- Todo の追加欄に Slack のメッセージのリンクを貼ると、Claude Code がスレッド全体を要約し（長いスレッドは途中を何回かに分けて）、やることを名前、要点の短い箇条書きとリンクを説明、期限を日付にしたタスクの案を確認用のカードに出す。追加先は Claude Code が推奨したプロジェクトが初めから入り、期限はカレンダーでも選べる。名前・説明・期限・追加先のプロジェクトを直して「追加」を押すと、Todoist にタスクを作る（Claude Code を使えるときだけ。使っている Claude のアカウント（API キーのときは「API キー」）はサイドメニューに表示する）
- その要約のしかたの指示を、Todo 一覧の見出しの Claude のアイコン、設定の Claude タブ、確認用のカードのどれかから開く画面で確認・編集し、デフォルトに戻せる。Claude Code との会話でも変更を頼める（変更案は差分で出て、「適用」と「保存」で確定する。頼みは複数行で書け、⌘Enter で送る。「クリア」で会話を消せる。頼みを書く欄の下で、この会話のモデルと effort を切り替えられる。Slack のメッセージは送らない）
- 設定の Claude タブの「モデルと effort」で、Claude Code に使わせるモデル（Haiku・Sonnet・Opus）と effort（low・medium・high・xhigh・max）を、Slack の要約、メールの要約、プロンプトの会話、Slack に貼る文章の校正、Slack のスレッドの相談のそれぞれに選べる（初期値は Sonnet と medium、Slack のスレッドの相談だけ Sonnet と high。モデルを変えると、そのモデルの推奨の effort に切り替わる）
- Claude Code は、Claude のサブスクリプションのほかに、Anthropic の API キーでも使える。設定の Claude タブで方式を選ぶ（API キーは呼び出しごとに課金される。キーに切り替えると、この端末の Claude Code はログアウトされる）
- 起動したときとカレンダーを開いたときは、前回取得した受信トレイ・予定・Todo を設定フォルダから先に表示し、取得が終わったら最新の内容に描き直す
- 新しい版が GitHub Releases に出ると、右下にポップアップが現れ、設定のアイコンと、設定の「アップデート」タブに赤い点が付く。ポップアップの「更新して再起動」を押すと、新しい版をダウンロードして署名を確かめ、入れ替えて再起動する（macOS の Apple Silicon のみ。起動時と 5 分ごとに確認する）。「あとで」で閉じると、同じ版ではアプリを終了するまで出ない（新しい版が出れば、また出る）
- 設定の「アップデート」タブに、いま動いている版を表示する。更新の方法は「手動」と「自動」から選べる（初期値は自動）。手動は上の動きで、自動は新しい版が見つかり次第、裏で入れ替える（再起動はしない。ポップアップが「新しい版の準備ができました」になり、「再起動」を押すと再起動する）。新しい版があるときは、このタブにも同じボタンが出る（「あとで」のあとも出る）。「今すぐ確認」で、すぐに確かめ直せる
- サイドメニューの Orca のアイコンで、Orca のプロジェクトを、作業中のものを先頭に、それぞれ最近動いた順に一覧する（状態のアイコンとセッション数を出し、SSH の接続先も並べる）。ベルで「入力待ち」「作業中」「完了」に分けた Claude のセッションの一覧に切り替える（入力待ちと、完了や中断で止まって未確認のセッションの件数はサイドメニューのアイコンにも出す。作業中のセッションがある間は、アイコンが黄色になってゆっくり明滅する。一覧の幅はドラッグで変えられる）。右のペインではプロジェクトのセッションをタブで切り替え、タブから閉じられる。タブはどれもセッションのターミナルで、そのまま打ち込める。最後のタブのすぐ右の＋から「Claude を起動」か「ターミナルを開く」を選ぶと、左で選んでいるプロジェクトか SSH の接続先の worktree で始め、そのタブを開く（worktree が 2 件以上なら選ぶ画面を出す）。作業ペインは左右と上下に、数の制限なく分割できる。タブの右クリックの「右に分割」「下に分割」か、タブを別のペインの端へドラッグして分け、タブ列か中央へ落とすとそのペインに移る。ペインはそれぞれタブ列と＋を持ち、タブが無くなったペインは閉じる。分割はプロジェクトごとに保存し、開き直すと戻る。ターミナルで Claude を起動しても（終わってシェルに戻っても）、そのタブは同じペインの同じ位置に残る。接続先は左ペインの下端で、このマシンか Orca に保存したサーバーから選ぶ（`orca` CLI と Orca のペアリング情報を使う。アプリは履歴を保存しない）
- 保存したサーバーでは、一覧とターミナルを Orca から流れてくるデータで描く（読み直しの待ちがなく、色も出る）。ターミナルはペインの大きさに合わせて描き、打ち込むたびにその大きさを Orca に伝える。Orca 本体で同じターミナルを開いていても、Orca から届く大きさに従って描くので崩れない
- 「Orca に渡す」のペインの履歴に出た Claude の質問に、その箱の中で答える。選択肢を選び、「回答を送る」で送る
- 開いているメール、Slack のスレッド、Todo の内容を、その画面の右ペインから Orca に渡す。送り先（worktree を選んだ新しいセッションか、動いているセッション）を選び、渡す内容を確かめ、指示を書いて自分で送る。起動後は同じペインで履歴を読み、追加の指示を送れる。渡した内容は履歴では 1 行に畳まれ、押すと開く
- このマシンの Orca のターミナルは、画面を読んで写す。色は出ず、`claude` のような全画面のプログラムは近似になる
- Orca 画面のターミナルに出た URL は、⌘ を押しながらクリックすると既定のブラウザで開く（http と https だけ。修飾キーなしのクリックは選択のまま）。リンクの上ではその URL を出す
- Orca 画面のターミナルで、Claude Code のようにマウスを使うプログラムが選んだ文字列をコピーできる（プログラムが OSC 52 で送る内容をクリップボードに入れる。入らなかったときは ⌘C か「編集 > コピー」で入る）。Option を押しながらドラッグすると、ターミナル側で文字を選べる
- Orca 画面のターミナルに、Ghostty の設定（フォント、配色とテーマ、文字を送るキーの割り当て）を取り込む。設定の「Orca」タブの「取り込む」で一度だけ読み、取り込めなかった項目は理由とともに出す。ターミナルの Shift+Enter は改行になり、Claude Code の入力で送信せずに改行できる
- Orca 画面のターミナルの配色を、設定の「Orca」タブの「ターミナルの配色」で、ライトとダークそれぞれ Orca の組み込みテーマから選ぶ。システムの外観に合わせて切り替わる。最初は、この Mac の Orca で選ばれているテーマを取り込む。Ghostty から取り込んだ色より、ここで選んだテーマが優先する。外観は「システムに合わせる」「ライト」「ダーク」から選べ、「ライト」か「ダーク」ならシステムの外観に関係なくそのテーマで描く
- Orca のターミナルと「Orca に渡す」のペインに、画像を貼り付けかドロップで添付する。画像は worktree の `.orca/drops/` に置かれ、そのパスが入力に入る
- Claude Code から、受信トレイの一覧・閲覧・アーカイブ・既読化・ゴミ箱への移動と、予定の一覧を扱う（ローカルの MCP サーバー `cookapps-mcp`。設定は [Claude との連携（MCP）](mcp.md)）
