# 機能

機能の一覧です。

- 複数の Gmail アカウントを追加し、全アカウントの受信トレイを 1 つの一覧で表示する（未読を上、既読を下に分け、それぞれ新しい順）。アカウントの追加と、各アカウントの状態と未読の件数の確認は、設定の「Google」タブで行う
- スレッドを開いて本文を表示する（日本語の文字コードと HTML メールに対応。メールに埋め込まれた画像は表示する。外部の画像は既定では読み込まず、メッセージの「画像を表示」を押したときだけ取得し、その送信者のアドレスを覚えて、以後はその送信者のメッセージの画像を自動で表示する。自動で取得するのは、Gmail が付けた認証結果（Authentication-Results）が DMARC 合格、または From のドメインと一致する DKIM 署名の合格のメッセージだけで、そうでないメッセージは覚えた送信者でも「画像を表示」を押すまで取得しない。行を押すとすぐ詳細の画面に移り、件名と送り主を出して、本文が届くまで「読み込んでいます…」を出す（届くまで、戻る以外のボタンは押せない）。一度開いたスレッドを開き直すと、前に取った内容をすぐに出し、裏で Gmail に取り直して、返信が届いたときなど内容が変わっていたときだけ出し直す（開いた内容はメモリにだけ持ち、アプリを終了すると消える）。未読のスレッドを開くと既読になる。本文のリンクを押すと、既定のブラウザで開く。HTML の本文の中に文字で書かれた http と https の URL もリンクになる。本文は Gmail と同じ書体（Arial）で出し、メールが書体を指定していればそれに従う。テキスト形式のメールの本文も同じ書体で出し、設定でメールの画面の書体を選ぶとそれを使う。件名のすぐ上に、AI 要約（Claude Code を使えるときだけ）、Slack に貼る、Todo にする、ゴミ箱へ移動、アーカイブのボタンが右に寄せて 1 行に並び、本文をスクロールしても残る。上端の帯には「戻る」だけがある。複数のメッセージがあるスレッドでは、新しい順に並べ、最新のメッセージだけを一番上で開き、古いものは 1 行に畳んで、押すと開く）
- 最新のメッセージの日時の右にある返信のボタンで、スレッドの下に返信欄を開き、返信を書いて送る（欄はメールの画面の高さの半分を取り、メッセージはその上でスクロールするので、読みながら書ける。「返信」は最後のメッセージの差出人（Reply-To があればその宛先）に、「全員に返信」はその人と To のほかの人に送り、Cc の人を Cc に入れる。自分のアカウントは宛先に入れない。宛先はチップで並び、× で外せる。「Cc」「Bcc」を押すとその行が開き、アドレスを打って Enter かカンマを打つか、欄を離れるとチップになる。本文は Slack の投稿欄と同じく書式つきで書け（太字、斜体、取り消し線、リンク、リスト、引用、コード）、HTML のメールとテキストのメールを両方入れて送る。「送信」（⌘Enter でもよい）で、スレッドを受け取ったアカウントから、同じスレッドへの返信として送り、スレッドを読み直して、送ったメールを出す。失敗したときはエラーを出し、書いた内容は残る。送れたときと「破棄」で、欄を空にして閉じる。スレッドを離れると書きかけは消え、下書きは保存しない。ファイルは、「送信」の右のクリップで選ぶか、欄にドロップするか貼り付けて添付できる（本文の下にチップで並び、× で外せる。合計は 25 MB まで。ファイルはメモリにだけ持ち、保存もログへの記録もしない。送れなかったときは残り、送ったときと「破棄」とスレッドを離れたときに消える）。Gmail の `users.messages.send` で送り、スコープは `gmail.modify` のままなので、再ログインは要らない）
- 受信トレイの見出しの「作成」（鉛筆のアイコン）で、新しいメールを書く画面を開く（ダイアログではなく、メールの画面の中に開く。「差出人」は送るアカウントで、アカウントが複数あれば選べる。「宛先」「Cc」「Bcc」は返信欄と同じチップで、その下に「件名」と本文（テキスト）がある。下に固定した帯の「送信」で送り、送れたら「送信しました」と出して受信トレイに戻る。失敗したときはエラーを出し、書いた内容は残る。「戻る」と「破棄」は、書いた内容を捨てて受信トレイに戻る。ファイルは返信欄と同じく、「送信」の右のクリップ、ドロップ、貼り付けで添付できる）
- スレッドを開いているあいだと新しいメールを書く画面では、右側に Claude Code のペインを出す（左との仕切りで、画面の 33% から 50% まで幅を変えられる。右側の上の段のアイコンで、Claude Code と「Orca に渡す」のペインを切り替える。新しいメールには「Orca に渡す」は無い）。ペインは、スレッドや新しいメールを開いたときは閉じていて「Claude に相談しますか？」と「相談する」だけを出し、Claude Code は動かない。「相談する」か上の段の Claude のアイコンで開くと Claude Code が始まり、アイコンでもう一度押して閉じると終わる。Claude Code は、`tsunagiai-mcp` で開いているスレッドを読み、宛先、Cc、Bcc、件名、本文を読み書きする（書き込みのたびにターミナルで聞かれる。書いた内容はすぐ欄に入り、送信はしない。書いたあとは「元に戻す」で、新しい書き込みから順に戻せる。自分で書き換えると戻せなくなる）。見出しは「Claude」と「やり直す」で、Claude Code には `tsunagiai-mcp` だけを渡し、組み込みの道具とスキルは渡さない。別のスレッドか新しいメールを開くと、Claude Code は終わり、ペインは閉じた状態に戻る。Claude Code を使えるときだけ
- スレッドをアーカイブする・ゴミ箱へ移動する（詳細画面のボタン、または一覧の行にマウスを乗せると出るボタン）。直前の 1 件は Cmd+Z（Windows では Ctrl+Z）かお知らせの「元に戻す」で戻せる
- 一覧のチェックボックスで、スレッドを既読・未読にする（未読の行には緑の点が付く）。未読の行の上の見出し「未読」の右端の「すべて既読にする」で、一覧に出ている未読のスレッドをまとめて既読にでき（最大 4 件ずつ送る。失敗した行は未読に戻してエラーを出す）、通知の「元に戻す」で未読に戻せる
- サイドメニューのアカウントのアイコンから、そのアカウントをつなぎAIから削除する（Google 側のアクセス権も取り消す。Gmail のメールは消えない）
- 約 10 秒ごとに受信トレイを Gmail と同期し、新着や他の端末での既読化・アーカイブを自動で反映する。一覧の上のヘッダーに「受信トレイ」が付き（スクロールしても残る）。最初の読み込みが返るまでは「読み込んでいます…」、スレッドが 0 件のときは「受信トレイにスレッドはありません」を出す。読み込みに失敗したときは、一覧の上に「読み込めませんでした: …。自動でも読み直します」と「再読み込み」のボタンを出し（前の一覧があるときは一覧を残す。別の画面へ移って戻っても残り、次の読み込みが成功すると消える）、前の読み込みから 60 秒たつと自動で読み直し、続けて失敗するたびに間隔を倍にする（最長 5 分）。スレッドを開いている間に再ログインが必要になったときは、次の同期で一覧を読み直す
- 未読のスレッドの件数を、サイドメニューの受信トレイのボタンに表示する（0 件のときは消える。macOS の Dock のアイコンのバッジには、この件数と、Todo の期限が来た未完了の件数、Slack の未読の件数、Orca の確認待ちの件数の合計を表示する。期限の時刻が過ぎるとウィンドウが隠れていても自動で増える）
- どの画面でも、ウィンドウの下にフッターがあり、右端のベルのアイコンに、受信トレイの未読のスレッドと Slack の一覧の未読のメッセージの合計を、サイドメニューの数と同じ形のバッジでベルの右上に重ねて出す（100 以上は「99+」、0 件のときは数を出さない）。ベルを押すと右からペインが開き、未読のメールと Slack のメッセージを混ぜて新しい順に並べる（差出人のアイコンと名前、Slack はチャンネル、時刻と、メールは件名と本文の抜粋、Slack は本文を、3 行まで折り返して）。行を押すと、メールか Slack の画面に移ってそのスレッドを開く（Slack のメッセージは一覧の行を押したときと同じく既読になる）。行にマウスかフォーカスが乗っている間は、メールでは「ゴミ箱へ移動」「アーカイブ」、Slack では「既読にする」（押して何か変わるときだけ）と「ウォッチ」のボタンを出し、押すと行はすぐにペインから消える（メールは通知の「元に戻す」で戻せる）。ベル、ペインの閉じるボタン、ペインの外を押すと閉じる。開いている間に未読が 0 件になったときも閉じる
- 設定は「Google」「カレンダー」「Todoist」「Slack」「Notion」「Claude」「スキル」「開発」「フォント」「アップデート」「ログ」の 11 個のタブに分かれ、開くと Google のタブが出る。「設定」の見出しとタブは、カードをスクロールしても上に残る
- 設定の「Notion」タブで、Notion のワークスペースを連携する。「追加」で既定のブラウザが開き、ワークスペースを選んで許可する。連携したワークスペースは 1 つずつ行になり、ユーザーの名前とメールアドレス、「使える」か「再連携が要る」かを出す。再連携が要るときは、「追加」で同じワークスペースを許可し直す。行のボタンで、確認のあとに解除する（Notion 側の許可も取り消す）。トークンはキーチェーンにだけ置き、画面には出さない。Notion のページを出す画面は、まだない
- 設定の「開発」タブの「Jira 接続」で、Jira Cloud（`https://{名前}.atlassian.net`）の接続を保存する。サイトの URL、メールアドレス、API トークンを入れて「保存」を押す。メールアドレスがあればアカウントの API トークンで、空ならスコープ付きのトークンで、`api.atlassian.com` を通してつなぐ。トークンを空のまま保存すると、保存済みのトークンを使い続ける。「接続を試す」で、入れた値で誰としてつながるかを Jira に問い合わせ、「接続できました」とユーザーか、「接続できません」を出す（保存はしない）。トークンはキーチェーンにだけ置き、画面には出さない。自分で立てた Jira（Server、Data Center）にはつながらない
- 全アカウントの Google Calendar の予定を、1 つの週表示にまとめて表示する（サイドメニューのカレンダーのアイコンで開く）。自分が未定と答えた予定は斜線、まだ返信していない予定は色を反転して表示する。週の始まりの曜日は、設定の「カレンダー」タブで日曜から土曜の中から選べる（初期値は日曜）
- カレンダー画面の週表示の上の帯は Todo と同じ色で、画面の幅いっぱいに通る。左から、パネルを畳むボタン、「今日」、前後の週の矢印、「2026年11月」の形の月を並べ、右端に Claude のアイコンがある。パネルを畳んでも開いても、帯のボタンは動かない。月を押すと、その下に月のカレンダーが開き、日付を押すとその週を出す（パネルを畳んでいても使える）
- カレンダー画面の週表示の左にパネルがあり、表示するカレンダーをチェックボックスで選ぶ。アカウントごとに、サイドバーと同じ頭文字の丸とメールアドレスの行の下に、「マイカレンダー」（自分が持ち主のカレンダー）と「他のカレンダー」（追加した他の人のカレンダー、祝日、会議室など）を字下げして並べ、チェックボックスはカレンダーの色になる。アカウントの行を押すと、そのアカウントのカレンダーを畳める。パネルの上には月のカレンダーがあり、日付を押すとその週を出す。切り替えるとすぐ週表示が変わり、選んだ状態はアプリの設定フォルダに保存する（Google 側の表示設定は書き換えない。まだ選んでいないカレンダーは Google 側の表示設定に従う）。帯の左端のボタンでパネルを畳むと、週表示が広がる。MCP サーバーの list_events も、ここで選んだカレンダーだけを読む
- カレンダーの予定を押すと、その横に詳細を出す（日時、Meet に参加するボタンと URL のコピー、場所、説明、参加者の人数と承諾した人数、カレンダー名とアカウント、自分の回答）。詳細は週の取得と一緒に取り、押したときの通信はない。別の予定を押すと切り替わり、同じ予定をもう一度押すか、✕・Escape・外側のクリックで閉じる。自分が主催した予定で、自分が持ち主のカレンダーにあるものには、見出しの ✕ の左に鉛筆とゴミ箱が出る（次の項）
- カレンダーの週の空いた枠を押すと、押した時刻から 1 時間の仮の予定と、その横に作成の欄を出す（終日の帯を押すと終日の予定）。タイトル、開始と終了（「終日」のチェック）、ゲスト（アドレスを入れて Enter で並べ、× で外す）、「Google Meet のビデオ会議を追加」、説明、作成先のカレンダー（自分が持ち主のもの）を入れて「保存」を押すと、Google カレンダーに予定を作り、週を読み直す。ゲストがいれば招待メールが届き、Meet の URL は保存したときに作られる。作れなかったときは理由を出し、入れた内容は残す。この機能より前にログインしたアカウントは、「再ログイン」を押して予定の作成を許可する
- カレンダーの予定の詳細の見出しの鉛筆とゴミ箱で、予定を編集・削除する（自分が主催した予定で、自分が持ち主のカレンダーにあるものだけ。招待された予定と、他の人のカレンダーの予定には出ない）。鉛筆を押すと、予定の作成と同じ欄が、今の値（タイトル、開始と終了、終日、ゲスト、Meet、説明）を入れて、その予定の横に開く（カレンダーは表示だけで、変えられない）。「保存」を押すと、Google カレンダーの予定を書き換えて、週を読み直す。✕ か Escape で、何も変えずに閉じる。ゴミ箱を押すと、詳細の中に「「{タイトル}」を削除します。元に戻せません。」と確認が出て（ゲストがいれば「ゲストに取り消しが届きます。」も出る）、「削除」を押すと Google カレンダーの予定を消して、週を読み直す。ゲストがいる予定の書き換えと削除は、ゲストにも変更か取り消しが届く（書き換えで外したゲストにも届く）。繰り返しの予定は、押した回だけを書き換え・削除し、シリーズ全体は扱わない。失敗したときは理由を出し、入れた内容は残す。予定を変える許可が無いアカウントは、「再ログイン」を押して許可する
- カレンダー画面の帯の右端の Claude のアイコンで、週の右に Claude Code のペインを開け閉めする（画面を開いたときは閉じている。閉じると Claude Code は終わる）。見出しは「Claude」と「やり直す」で、Claude Code には `tsunagiai-mcp` だけを渡し、組み込みの道具とスキルは渡さない。Claude Code は auto mode で起動し、確認を聞かずに動く。渡すツールは `list_events`、`list_calendars`、`calendar_set_shown`、`calendar_create_event`、`calendar_update_event`、`calendar_delete_event`、`calendar_show_slots` の 7 つだけで、カレンダー画面でできることを Claude Code から使える。`list_events` は予定を、場所、説明（1,000 文字で切る）、Meet の URL、参加者の人数、自分の回答、カレンダー、予定の ID、編集と削除ができるかとともに読む。`list_calendars` はアカウントごとのカレンダーを、自分が持ち主かと表示しているかとともに読み、`calendar_set_shown` は表示するカレンダーを切り替える。`calendar_create_event`、`calendar_update_event`、`calendar_delete_event` は、画面と同じ確かめで予定を作り、書き換え、削除する（書き換えと削除は、自分が主催した予定で、自分が持ち主のカレンダーにあるものだけ。繰り返しの予定は、その回だけ）。予定を変えると、画面の週は読み直される。ゲストがすでにいる予定への変更と取り消しと、ゲストのいない予定の作成・編集・削除は、確認なしで Google に送る。新しい人をゲストに足すとき（ゲスト付きの予定の作成を含む）は、Claude Code は何も送らず、画面の作成か編集の欄に値を入れるだけで、「保存」は自分で押す。`calendar_show_slots` で空き時間の候補を週の上に描く。候補は 1 件から 8 件で、同じ日の中の開始と終了を、赤い破線の枠に「候補 1 10:00–11:00」の形で出す。次に描くと前の候補と置き換わる。帯には「候補 N 件」と ✕ が出て、✕ かペインを閉じると消える。枠の下の空いた場所を押すと、予定の作成が開く。候補は保存も送信もしない。Claude Code を使えるときだけ
