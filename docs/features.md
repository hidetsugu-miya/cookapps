# 機能

機能の一覧です。

- 複数の Gmail アカウントを追加し、全アカウントの受信トレイを 1 つの一覧で表示する（未読を上、既読を下に分け、それぞれ新しい順）。アカウントの追加と、各アカウントの状態と未読の件数の確認は、設定の「Google」タブで行う
- スレッドを開いて本文を表示する（日本語の文字コードと HTML メールに対応。メールに埋め込まれた画像は表示する。外部の画像は既定では読み込まず、メッセージの「画像を表示」を押したときだけ取得し、その送信者のアドレスを覚えて、以後はその送信者のメッセージの画像を自動で表示する。自動で取得するのは、Gmail が付けた認証結果（Authentication-Results）が DMARC 合格、または From のドメインと一致する DKIM 署名の合格のメッセージだけで、そうでないメッセージは覚えた送信者でも「画像を表示」を押すまで取得しない。行を押すとすぐ詳細の画面に移り、件名と送り主を出して、本文が届くまで「読み込んでいます…」を出す（届くまで、戻る以外のボタンは押せない）。未読のスレッドを開くと既読になる。本文のリンクを押すと、既定のブラウザで開く。HTML の本文の中に文字で書かれた http と https の URL もリンクになる。本文は Gmail と同じ書体（Arial）で出し、メールが書体を指定していればそれに従う。テキスト形式のメールの本文も同じ書体で出し、設定でメールの画面の書体を選ぶとそれを使う。件名のすぐ上に、AI 要約（Claude Code を使えるときだけ）、Slack に貼る、Todo にする、Orca に渡す、ゴミ箱へ移動、アーカイブのボタンが右に寄せて 1 行に並び、本文をスクロールしても残る。上端の帯には「戻る」だけがある。複数のメッセージがあるスレッドでは、新しい順に並べ、最新のメッセージだけを一番上で開き、古いものは 1 行に畳んで、押すと開く）
- スレッドをアーカイブする・ゴミ箱へ移動する（詳細画面のボタン、または一覧の行にマウスを乗せると出るボタン）。直前の 1 件は Cmd+Z（Windows では Ctrl+Z）かお知らせの「元に戻す」で戻せる
- 一覧のチェックボックスで、スレッドを既読・未読にする（未読の行には緑の点が付く）。未読の行の上の見出し「未読」の右端の「すべて既読にする」で、一覧に出ている未読のスレッドをまとめて既読にでき（最大 4 件ずつ送る。失敗した行は未読に戻してエラーを出す）、通知の「元に戻す」で未読に戻せる
- サイドメニューのアカウントのアイコンから、そのアカウントを cookapps から削除する（Google 側のアクセス権も取り消す。Gmail のメールは消えない）
- 約 10 秒ごとに受信トレイを Gmail と同期し、新着や他の端末での既読化・アーカイブを自動で反映する。一覧の上のヘッダーに「受信トレイ」が付き（スクロールしても残る）。最初の読み込みが返るまでは「読み込んでいます…」、スレッドが 0 件のときは「受信トレイにスレッドはありません」を出す。読み込みに失敗したときは、一覧の上に「読み込めませんでした: …。自動でも読み直します」と「再読み込み」のボタンを出し（前の一覧があるときは一覧を残す。別の画面へ移って戻っても残り、次の読み込みが成功すると消える）、前の読み込みから 60 秒たつと自動で読み直し、続けて失敗するたびに間隔を倍にする（最長 5 分）。スレッドを開いている間に再ログインが必要になったときは、次の同期で一覧を読み直す
- 同期で新着のメールが見つかると、ウィンドウの右下にカードを出す（差出人と件名、ゴミ箱へ移動・アーカイブ・詳細を開くのボタン。詳細を開くは他の画面からでもそのスレッドに移る。カードは最大 3 枚で、10 秒で消える（マウスやフォーカスが乗っている間は残る）。そのスレッドが既読になると（一覧やスレッドで既読にしたときも、他の端末で既読になったときも）すぐに消える。起動時の読み込みでは出さず、OS の通知も使わない）
- 未読のスレッドの件数を、サイドメニューの受信トレイのボタンに表示する（0 件のときは消える。macOS の Dock のアイコンのバッジには、この件数と、Todo の期限が来た未完了の件数の合計を表示する。期限の時刻が過ぎるとウィンドウが隠れていても自動で増える）
- 設定は「Google」「カレンダー」「Todoist」「Slack」「Claude」「Orca」「フォント」「アップデート」の 8 つのタブに分かれ、開くと Google のタブが出る。「設定」の見出しとタブは、カードをスクロールしても上に残る
- 全アカウントの Google Calendar の予定を、1 つの週表示にまとめて表示する（閲覧のみ。サイドメニューのカレンダーのアイコンで開く）。自分が未定と答えた予定は斜線、まだ返信していない予定は色を反転して表示する。週の始まりの曜日は、設定の「カレンダー」タブで日曜から土曜の中から選べる（初期値は日曜）
- カレンダー画面の週表示の上の帯は Todo と同じ色で、左から「今日」、前後の週の矢印、「2026年11月」の形の月を並べる。月を押すと、その下に月のカレンダーが開き、日付を押すとその週を出す（パネルを畳んでいても使える）
- カレンダー画面の週表示の左に「カレンダー」のパネルがあり、表示するカレンダーをチェックボックスで選ぶ。アカウントごとに、サイドバーと同じ頭文字の丸とメールアドレスの行の下に、「マイカレンダー」（自分が持ち主のカレンダー）と「他のカレンダー」（追加した他の人のカレンダー、祝日、会議室など）を字下げして並べ、チェックボックスはカレンダーの色になる。アカウントの行を押すと、そのアカウントのカレンダーを畳める。パネルの上には月のカレンダーがあり、日付を押すとその週を出す。切り替えるとすぐ週表示が変わり、選んだ状態はアプリの設定フォルダに保存する（Google 側の表示設定は書き換えない。まだ選んでいないカレンダーは Google 側の表示設定に従う）。見出しの横のボタンでパネルを畳むと、週表示が広がる。MCP サーバーの list_events も、ここで選んだカレンダーだけを読む
- カレンダーの予定を押すと、その横に詳細を出す（日時、Meet に参加するボタンと URL のコピー、場所、説明、参加者の人数と承諾した人数、カレンダー名とアカウント、自分の回答）。詳細は週の取得と一緒に取り、押したときの通信はない。別の予定を押すと切り替わり、同じ予定をもう一度押すか、✕・Escape・外側のクリックで閉じる
- Todoist のタスクを、プロジェクト別（Todoist と同じ親子関係でネストする）と「今日」の一覧で表示し、完了・追加・編集（説明とサブタスクを含む）する。説明は Markdown で表示し、10 行を超える説明は 10 行目で折りたたんで「… 続きを表示（残り n 行）」で全文を出し、押すと編集して「保存」で登録する。「今日」で追加した、日付の無いタスクは期限が今日になる。期限は月のカレンダーから選べる。一覧の行は 3 段で、タスク名、説明の 1 行目（URL は下線）、期限・ラベル・サブタスクの数（「今日」の一覧では右端にプロジェクト）の順に出す。サブタスクは一覧の行の左のトグルで開閉する。詳細画面の右にプロジェクトと日付を出し、日付はマウスを乗せると出る × で消せる。サブタスクの詳細には、名前の上に直接の親タスクを出し、↩ の「親タスク」で親を開く（左の丸いチェックで、親タスクを完了にできる）。親に説明があれば、親の名前を押すと、その説明をその場に開き（3 行目で切って「…」を付ける）、「コピー」で全文をコピーできる。もう一度押すと畳む。詳細画面の右の「ラベル」には、タスクのラベルを色の点と名前で並べ、× で外せる。＋で出る欄で、ラベルを絞り込んでタスクに付け外しし、無い名前は新しく作って付けられる。詳細画面の右上の「編集」メニューから、タスクのリンクや説明（Markdown のまま）をコピーしたり、タスクを削除したりできる（削除は二度押す）。説明は、文字を選んでコピーでき（選んでも編集は始まらない）、マウスを乗せると右上に出るコピーのアイコンでもコピーできる。一覧の行にマウスを乗せると、詳細を開かずに名前・期限・プロジェクトを変えられ、行の左端をドラッグして、左のプロジェクトへ移したり、別のタスクの行に落としてそのタスクのサブタスクにしたりすることもできる（落とせる行は枠で示す。自分自身、自分のサブタスク、今の親には落とせない）。サブタスクは、行にマウスを乗せると出る「親タスクから外す」ボタンか、今いるプロジェクトへのドラッグで、親から外して単独のタスクに戻せる。詳細画面のサブタスクの行（未完了のもの）も、一覧の行と同じく、マウスを乗せると出るボタンとドラッグで、別のプロジェクトへ移す、親から外す、詳細のほかのサブタスクの下へ入れる、ができる。詳細画面の下には、タスクのコメント（投稿者、日時、Markdown の本文、添付ファイル）を一覧し、コメントの追加と、ファイル 1 つ（100 MB まで）の添付ができる（⌘Enter か送信ボタンで送り、Enter は改行になる）。受信トレイのスレッドから「Todo にする」でタスクを作る。Todoist に接続できないときは、前回取得した内容を表示する（Todoist の個人 API トークンを使う。サイドメニューの Todo のアイコンで開き、期限（日付と時刻。時刻の無い日付は 0 時）が来た未完了の件数をそのアイコンに表示する。期限の無いタスクは数えない。接続の状態の確認と解除は、設定の「Todoist」タブで行う。一覧の見出しの ✳ のアイコンから、要約プロンプトの画面を開ける）
- Todo 画面の右側は、トークンの入力欄と下書きのページのあいだを除いて、いつも開いていて、2 段になっている。1 段目は、左の見出しと同じ淡い色の帯で、右端に Claude と「Orca に渡す」の 2 つのアイコンだけがあり、押して切り替える（Orca に渡すのアイコンは、タスクを開いているあいだだけ押せる。タスクを離れると Claude に戻る）。2 段目は選んだ機能の見出しと操作で、その下が中身になる。2 つのペインは同時には出ず、右側の幅は仕切りで画面の 30% から 45% まで変えられる（最初はいちばん狭い画面の 30%）。左の見出しには、Todo そのものの操作（一覧のボタン、戻るボタン、見出し、「編集」）だけが残る。Claude のペインでは、「年末まで週 2 件ずつ」のように言葉で頼むと、Claude がタスクの案を、名前、日付、プロジェクトのカードで返す。カードの上で名前、日付、プロジェクトを直し、「追加」を押して初めて Todoist にタスクを作る。「却下」は何も作らずにカードを閉じる。続けて頼むと、今のカードの内容も Claude に渡る。頼みを書く欄の枠の中で、この相談のモデルと effort を切り替えられる（依頼、会話、今日の日付、Todoist のプロジェクトの名前を送る。Claude Code を使えるときだけ）
- メールを Slack に貼る（詳細画面の「Slack に貼る」で専用の画面が開き、左に投稿のプレビュー、右に Claude との会話が並ぶ。プレビューには、スレッドの最新のメッセージの件名・差出人・日時・本文が入り、押すと編集欄になって直せる。左下の「投稿」で、選んだチャンネルかスレッドに投稿する。「元の内容に戻す」で最初の文に戻せる。宛先は、左上の「貼り付け先」で、最近使った先、参加しているチャンネルの検索、Slack のリンクから選ぶ（Claude に選ばせることもできる）。複数のワークスペースを持て、トークンはサイドメニューの設定で追加する）
- サイドメニューは、開いている画面に合わせて、その機能のアカウントを、アイコンの下に並べる（メールとカレンダーでは Google のアカウントをカレンダーのアイコンの下に、Slack ではワークスペースを Slack のアイコンの下に出す。Todo と設定では出さない。ワークスペースの絵は、そのワークスペースでの自分のアイコン）
- サイドメニューの Slack のアイコンで Slack の画面を開く。画面の左のサイドメニューに、「未読メッセージ」（未読の件数つき）と「ウォッチ」の 2 つのボタンと、ワークスペースごとのチャンネル（参加しているパブリックとプライベート。名前順で、未読の件数つき。DM とグループ DM は出さない）が並び、ワークスペースの名前を押すと、未読の無いチャンネルを隠して畳める（畳んだ状態はアプリを開き直しても残る）。境目をドラッグして幅を変えられる。ボタンで、全ワークスペース分のメッセージの「未読」と「ウォッチ」の一覧を 1 つずつ切り替える（送信者のアイコンと名前、本文（省略せずに全部。ボットの投稿は項目ごとに書式つきで）、返信の件数と、返信した人のアイコン（5 人まで）と最終返信の時刻を出す。新着は自動で読み直す。設定の「Slack」タブの「リアルタイム更新」でワークスペースごとに App-Level Token を登録すると、Socket Mode でつなぎ、投稿・返信・変更・削除を約 1 秒で一覧と未読の件数に出す）。「未読」は、チャンネルごとにまとめ、チャンネルごとに新しい 10 件までを、古い順に日付の区切りの下に、名前の横に時刻をつけて出す（全体の上限はない）。「ウォッチ」は新しい順で、行に日時を出す。未読のメッセージは、既読になると一覧から消える。一覧の上のヘッダーには「Slack」の見出しと、「一覧に出さないチャンネル」を開く設定のアイコンだけが付く。未読の件数は Slack のアイコンにも出す（20 件を超えると `20+`。0 件のときは消える）。サイドメニューのチャンネルにマウスを乗せると出る丸にマイナスのアイコンで、そのチャンネルを一覧に出さないようにでき、設定の「Slack」タブで戻せる。しおりで、そのスレッドをウォッチでき、ウォッチしたスレッドは外すまで「ウォッチ」に残り、新しい返信があると「新しい返信 N 件」を出す
- 「未読」のチャンネルの見出しの右端のアイコン「既読にする」で、そのチャンネルの既読位置を最新の未読のメッセージまで進める（一覧に出ていない分も含む。戻せない）。そのチャンネルのスレッドの未読の返信も既読になる。スレッドは開かない。1 件ずつ既読にするチェックと、一覧全体の「すべて既読にする」はない
- 未読の返信があるスレッドは未読の段に出し、行の下の「未読の返信 N 件」で返信を開閉する（最初は開いている。ここで読んでも Slack 側のスレッドの未読は消えない）
- サイドメニューのチャンネルを押すと、そのチャンネルの履歴を開く（最新の 50 件を、古い順に日付の区切りの下に出し、最新のメッセージの位置で開く。ヘッダーはチャンネルの名前とワークスペースの名前だけ。行は未読の行と同じで、返信のあるメッセージは「N 件の返信」でスレッドを開き、しおりでウォッチできる。リアクションは、本文の下に絵文字と数で並び（カスタム絵文字は画像で出す。画像を読むには `emoji:read` が要り、なければ `:名前:` で出す）、押して付け外しできる（自分が付けたものは枠の色が変わる。付け外しには `reactions:write` が要る）。最後の「☺+」でピッカーを開き、絵文字を検索して付けられる（最近・このワークスペース・標準の順。このアプリを開いている間に付けたものが「最近」に並ぶ）。スレッドへの返信をチャンネルにも投稿したメッセージには、本文の上に薄い色で「スレッドに返信済み: 」と元のメッセージの書き出しを出し、押すとそのスレッドを開く。チャンネルを押すと、「未読」の見出しの「既読にする」と同じく、そのチャンネルを既読にする。読めないときはエラーと「再読み込み」を出す）
- チャンネルの履歴の下の欄から、そのチャンネルに投稿できる（欄は書式つきで書け、枠の上の段のボタンで、選んだ文字を太字、斜体、取り消し線、リンク、番号付きリスト、箇条書き、引用、コード、コードブロックにできる。Enter は改行、⌘Enter（Windows は Ctrl+Enter）か枠の右下の矢印で、自分の名前で投稿する。書式は Slack の書き方に直して送り、リンクは http、https、mailto のアドレスだけをリンクにする。空の文章は投稿できず、10,000 文字まで。投稿できたら欄を空にして履歴を読み直し、最新のメッセージを出す。失敗したときはエラーを出して文章を残す。書きかけの文章は、チャンネルごとにアプリを終了するまで残る）
- Slack の一覧の読み込みで新しい未読のメッセージが見つかると、ウィンドウの右下にカードを出す（送信者のアイコンと名前、チャンネル、本文を 1 行で。既読にする・ウォッチ・スレッドを開くのボタン。スレッドを開くは他の画面からでもそのスレッドに移る。新着メールのカードと同じ積み重ねで、合わせて最大 3 枚。10 秒で消える（マウスやフォーカスが乗っている間は残る）。そのメッセージが未読でなくなると（一覧や Slack で既読にしたときも、チャンネルを一覧から外したときも、ウォッチしたときも）すぐに消える。起動後の最初の読み込みと、ウォッチしたスレッドでは出さず、OS の通知も使わない）
- 一覧の行を押すと、そのスレッドの詳細が開く（メッセージを古い順に、送信者のアイコン、名前、時刻、本文で出す。本文の Slack の書式（`*太字*`、`_斜体_`、`~取り消し~`、`` `コード` ``、``` で囲んだコードブロック、`>` で始まる引用）は、その見た目で出す。添付の画像はサムネイルで、画像でないファイルは名前の札で出し、押すと Slack で開く。ボットやアプリの投稿のブロックと添付のカードも出す（URL 付きのボタンは既定のブラウザで開く。画像は「画像を表示」を押したときだけ取得する。添付の長い本文は最初の 5 行で畳み、「もっと表示する」で全文を出す。別のメッセージを共有した投稿では、そのメッセージへのリンクを「メッセージ」というラベルで出す）。メッセージのリアクションは、本文の下に絵文字と数で並び、チャンネルの履歴と同じく、カスタム絵文字は画像で出し、押して付け外しでき、「☺+」のピッカーから付けられる。「Slack で開く」と、「Todo にする」（Claude Code と Todoist が使えるときだけ。要約のカードは「[Slack のメッセージを要約して Todo にする](slack.md#slack-のメッセージを要約して-todo-にする)」と同じ）がある）
- スレッドの詳細の下の欄から、スレッドに返信できる（欄はチャンネルの投稿欄と同じく書式つきで書け、Enter は改行、⌘Enter（Windows は Ctrl+Enter）か枠の右下の矢印で投稿する。書きかけの文章と Claude との会話は、アプリを終了するまでスレッドごとに残る）

- Orca 画面のファイル欄の上の段の「ファイル」と「履歴」のアイコンで、ファイルの木と git の履歴を切り替える。履歴は worktree のコミットを新しい順に並べ（件名、短い ID、日時）、末尾までスクロールすると続きを読む。コミットを押すと、その下に、そのコミットで変わったファイルを、変わり方（M、A、D、R、C）、名前、フォルダ、増えた行と消えた行の数で出す。ファイルをダブルクリックする（か Enter を押す）と、親のコミットのファイルを左、そのコミットのファイルを右にした差分を、作業ペインのタブで出す（見た目とボタンは HEAD との差分と同じ。タブの名前にはコミットの短い ID が付く）。SSH ホストの worktree では履歴は出ない
- Orca 画面のファイル欄の見出しのブランチ名を押すと、真下にブランチの一覧が開き、選んだブランチに worktree を切り替える。一覧は「ローカル」と「リモート」に分かれ、今のブランチに印が付く。別の worktree で使っているブランチは薄く出て選べない。上の欄に打つと絞り込み、リモートはその文字で探す。リモートのブランチを選ぶと、それを追うローカルのブランチを作って切り替える。切り替えるとファイル一覧と見出しを読み直し、開いているタブはそのまま残る。コミットしていない変更があるときなど、Orca が断ったときはその文言を出す。SSH ホストの worktree では押せない
- 設定の「フォント」タブで、画面ごとに書体と大きさを選ぶ。メール、カレンダー、Slack は画面ごとに、Todo は左のプロジェクト一覧と右の作業スペースを別々に、Orca はプロジェクト一覧、作業スペース（チャットとファイル）、作業スペース（ターミナル）、エディタを別々に選べる。「アプリ全体」では、設定画面、サイドメニュー、ポップアップなど、画面ごとの場所に入らない部分の書体と大きさを選び、「等幅の文字」では、コード、プロンプト、差分の書体を選ぶ。テキスト形式のメールの本文は、メールの画面の書体と大きさで出す。HTML のメールの本文は、メールが指定した書体のまま出す。選んだ書体はすぐに画面に出る。初めはどの画面も今までと同じで、Orca の作業スペースだけは Ghostty の設定に従うこともできる
- ウィンドウにタイトルバーは無く、どの画面もウィンドウの上端まで広がる。macOS の閉じる・しまう・拡大のボタンは左のアイコン列の上に乗る。各画面の上端の帯は、どの画面も同じ高さ（40px）で、中のボタンも同じ大きさにそろえてある。画面のフォントを大きくすると、帯は文字に合わせて伸びる。帯の空いた所をドラッグするとウィンドウが動き、ダブルクリックで拡大する
- Orca 画面と Todo 画面の左のプロジェクト一覧は、ボタンで閉じられる（閉じている間は、右の作業ペインかタスクの一覧がその幅まで広がる。もう一度押すと開く。状態は保存せず、起動すると開いている）。Orca 画面のボタンは、開いている間は一覧の上端の左に、閉じている間は左端のペインのタブ列の左にあり、どちらも同じ横の位置に出る。Todo 画面のボタンは一覧の上端の左にあり、閉じている間は見出しの左に移る
