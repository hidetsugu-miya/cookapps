# 機能

機能の一覧です。

- 複数の Gmail アカウントを追加し、全アカウントの受信トレイを 1 つの一覧で表示する（未読を上、既読を下に分け、それぞれ新しい順）。アカウントの追加と、各アカウントの状態と未読の件数の確認は、設定の「Google」タブで行う
- スレッドを開いて本文を表示する（日本語の文字コードと HTML メールに対応。メールに埋め込まれた画像は表示する。外部の画像は既定では読み込まず、メッセージの「画像を表示」を押したときだけ取得し、その送信者のアドレスを覚えて、以後はその送信者のメッセージの画像を自動で表示する。自動で取得するのは、Gmail が付けた認証結果（Authentication-Results）が DMARC 合格、または From のドメインと一致する DKIM 署名の合格のメッセージだけで、そうでないメッセージは覚えた送信者でも「画像を表示」を押すまで取得しない。行を押すとすぐ詳細の画面に移り、件名と送り主を出して、本文が届くまで「読み込んでいます…」を出す（届くまで、戻る以外のボタンは押せない）。一度開いたスレッドを開き直すと、前に取った内容をすぐに出し、裏で Gmail に取り直して、返信が届いたときなど内容が変わっていたときだけ出し直す（開いた内容はメモリにだけ持ち、アプリを終了すると消える）。未読のスレッドを開くと既読になる。本文のリンクを押すと、既定のブラウザで開く。HTML の本文の中に文字で書かれた http と https の URL もリンクになる。本文は Gmail と同じ書体（Arial）で出し、メールが書体を指定していればそれに従う。テキスト形式のメールの本文も同じ書体で出し、設定でメールの画面の書体を選ぶとそれを使う。件名のすぐ上に、AI 要約（Claude Code を使えるときだけ）、Slack に貼る、Todo にする、Orca に渡す、ゴミ箱へ移動、アーカイブのボタンが右に寄せて 1 行に並び、本文をスクロールしても残る。上端の帯には「戻る」だけがある。複数のメッセージがあるスレッドでは、新しい順に並べ、最新のメッセージだけを一番上で開き、古いものは 1 行に畳んで、押すと開く）
- 最新のメッセージの日時の右にある返信のボタンで、スレッドの下に返信欄を開き、返信を書いて送る（欄はメールの画面の高さの半分を取り、メッセージはその上でスクロールするので、読みながら書ける。「返信」は最後のメッセージの差出人（Reply-To があればその宛先）に、「全員に返信」はその人と To のほかの人に送り、Cc の人を Cc に入れる。自分のアカウントは宛先に入れない。宛先はチップで並び、× で外せる。「Cc」「Bcc」を押すとその行が開き、アドレスを打って Enter かカンマを打つか、欄を離れるとチップになる。本文は Slack の投稿欄と同じく書式つきで書け（太字、斜体、取り消し線、リンク、リスト、引用、コード）、HTML のメールとテキストのメールを両方入れて送る。「送信」（⌘Enter でもよい）で、スレッドを受け取ったアカウントから、同じスレッドへの返信として送り、スレッドを読み直して、送ったメールを出す。失敗したときはエラーを出し、書いた内容は残る。送れたときと「破棄」で、欄を空にして閉じる。スレッドを離れると書きかけは消え、下書きは保存しない。ファイルは添付できない。Gmail の `users.messages.send` で送り、スコープは `gmail.modify` のままなので、再ログインは要らない）
- 受信トレイの見出しの「作成」（鉛筆のアイコン）で、新しいメールを書く画面を開く（ダイアログではなく、メールの画面の中に開く。「差出人」は送るアカウントで、アカウントが複数あれば選べる。「宛先」「Cc」「Bcc」は返信欄と同じチップで、その下に「件名」と本文（テキスト）がある。下に固定した帯の「送信」で送り、送れたら「送信しました」と出して受信トレイに戻る。失敗したときはエラーを出し、書いた内容は残る。「戻る」と「破棄」は、書いた内容を捨てて受信トレイに戻る。ファイルは添付できない）
- スレッドをアーカイブする・ゴミ箱へ移動する（詳細画面のボタン、または一覧の行にマウスを乗せると出るボタン）。直前の 1 件は Cmd+Z（Windows では Ctrl+Z）かお知らせの「元に戻す」で戻せる
- 一覧のチェックボックスで、スレッドを既読・未読にする（未読の行には緑の点が付く）。未読の行の上の見出し「未読」の右端の「すべて既読にする」で、一覧に出ている未読のスレッドをまとめて既読にでき（最大 4 件ずつ送る。失敗した行は未読に戻してエラーを出す）、通知の「元に戻す」で未読に戻せる
- サイドメニューのアカウントのアイコンから、そのアカウントをつなぎAIから削除する（Google 側のアクセス権も取り消す。Gmail のメールは消えない）
- 約 10 秒ごとに受信トレイを Gmail と同期し、新着や他の端末での既読化・アーカイブを自動で反映する。一覧の上のヘッダーに「受信トレイ」が付き（スクロールしても残る）。最初の読み込みが返るまでは「読み込んでいます…」、スレッドが 0 件のときは「受信トレイにスレッドはありません」を出す。読み込みに失敗したときは、一覧の上に「読み込めませんでした: …。自動でも読み直します」と「再読み込み」のボタンを出し（前の一覧があるときは一覧を残す。別の画面へ移って戻っても残り、次の読み込みが成功すると消える）、前の読み込みから 60 秒たつと自動で読み直し、続けて失敗するたびに間隔を倍にする（最長 5 分）。スレッドを開いている間に再ログインが必要になったときは、次の同期で一覧を読み直す
- 未読のスレッドの件数を、サイドメニューの受信トレイのボタンに表示する（0 件のときは消える。macOS の Dock のアイコンのバッジには、この件数と、Todo の期限が来た未完了の件数、Slack の未読の件数、Orca の確認待ちの件数の合計を表示する。期限の時刻が過ぎるとウィンドウが隠れていても自動で増える）
- どの画面でも、ウィンドウの下にフッターがあり、右端のベルのアイコンに、受信トレイの未読のスレッドと Slack の一覧の未読のメッセージの合計を出す（100 以上は「99+」、0 件のときは数を出さない）。ベルを押すと右からペインが開き、未読のメールと Slack のメッセージを混ぜて新しい順に並べる（差出人のアイコンと名前、Slack はチャンネル、時刻と、メールは件名と本文の抜粋、Slack は本文を、3 行まで折り返して）。行を押すと、メールか Slack の画面に移ってそのスレッドを開く（Slack のメッセージは一覧の行を押したときと同じく既読になる）。行にマウスかフォーカスが乗っている間は、メールでは「ゴミ箱へ移動」「アーカイブ」、Slack では「既読にする」（押して何か変わるときだけ）と「ウォッチ」のボタンを出し、押すと行はすぐにペインから消える（メールは通知の「元に戻す」で戻せる）。ベル、ペインの閉じるボタン、ペインの外を押すと閉じる（開発の画面では、フッターの左端にモードの切り替えも出る）
- 設定は「Google」「カレンダー」「Todoist」「Slack」「Claude」「スキル」「Orca」「フォント」「アップデート」「ログ」の 10 個のタブに分かれ、開くと Google のタブが出る。「設定」の見出しとタブは、カードをスクロールしても上に残る
- 全アカウントの Google Calendar の予定を、1 つの週表示にまとめて表示する（閲覧のみ。サイドメニューのカレンダーのアイコンで開く）。自分が未定と答えた予定は斜線、まだ返信していない予定は色を反転して表示する。週の始まりの曜日は、設定の「カレンダー」タブで日曜から土曜の中から選べる（初期値は日曜）
- カレンダー画面の週表示の上の帯は Todo と同じ色で、左から「今日」、前後の週の矢印、「2026年11月」の形の月を並べる。月を押すと、その下に月のカレンダーが開き、日付を押すとその週を出す（パネルを畳んでいても使える）
- カレンダー画面の週表示の左に「カレンダー」のパネルがあり、表示するカレンダーをチェックボックスで選ぶ。アカウントごとに、サイドバーと同じ頭文字の丸とメールアドレスの行の下に、「マイカレンダー」（自分が持ち主のカレンダー）と「他のカレンダー」（追加した他の人のカレンダー、祝日、会議室など）を字下げして並べ、チェックボックスはカレンダーの色になる。アカウントの行を押すと、そのアカウントのカレンダーを畳める。パネルの上には月のカレンダーがあり、日付を押すとその週を出す。切り替えるとすぐ週表示が変わり、選んだ状態はアプリの設定フォルダに保存する（Google 側の表示設定は書き換えない。まだ選んでいないカレンダーは Google 側の表示設定に従う）。見出しの横のボタンでパネルを畳むと、週表示が広がる。MCP サーバーの list_events も、ここで選んだカレンダーだけを読む
- カレンダーの予定を押すと、その横に詳細を出す（日時、Meet に参加するボタンと URL のコピー、場所、説明、参加者の人数と承諾した人数、カレンダー名とアカウント、自分の回答）。詳細は週の取得と一緒に取り、押したときの通信はない。別の予定を押すと切り替わり、同じ予定をもう一度押すか、✕・Escape・外側のクリックで閉じる
- Todoist のタスクを、プロジェクト別（Todoist と同じ親子関係でネストする）と「今日」の一覧で表示し、完了・追加・編集（説明とサブタスクを含む）する。説明は Markdown で表示し、10 行を超える説明は 10 行目で折りたたんで「… 続きを表示（残り n 行）」で全文を出し、押すと編集して「保存」で登録する。「今日」で追加した、日付の無いタスクは期限が今日になる。期限は月のカレンダーから選べる（今日は緑の輪で囲む）。一覧の行は 3 段で、タスク名、説明の 1 行目（URL は下線）、期限・ラベル・サブタスクの数（「今日」の一覧では右端にプロジェクト）の順に出す。サブタスクは一覧の行の左のトグルで開閉する。詳細画面の右にプロジェクトと日付を出し、日付はマウスを乗せると出る × で消せる。サブタスクの詳細には、名前の上に直接の親タスクを出し、↩ の「親タスク」で親を開く（左の丸いチェックで、親タスクを完了にできる）。親に説明があれば、親の名前の下にその説明をいつも出す（3 行目で切って「…」を付ける。文字は選んでコピーできる）。詳細画面の右の「ラベル」には、タスクのラベルを色の点と名前で並べ、× で外せる。＋で出る欄で、ラベルを絞り込んでタスクに付け外しし、無い名前は新しく作って付けられる。詳細画面の右上の「編集」メニューから、タスクのリンクや説明（Markdown のまま）をコピーしたり、タスクを削除したりできる（削除は二度押す）。説明は、文字を選んでコピーでき（選んでも編集は始まらない）、マウスを乗せると右上に出るコピーのアイコンでもコピーできる。一覧の行にマウスを乗せると、詳細を開かずに名前・期限・プロジェクトを変えられ、行の左端をドラッグして、左のプロジェクトへ移したり、別のタスクの行に落としてそのタスクのサブタスクにしたりすることもできる（落とせる行は枠で示す。自分自身、自分のサブタスク、今の親には落とせない）。サブタスクは、行にマウスを乗せると出る「親タスクから外す」ボタンか、今いるプロジェクトへのドラッグで、親から外して単独のタスクに戻せる。詳細画面のサブタスクの行（未完了のもの）も、一覧の行と同じく、マウスを乗せると出るボタンとドラッグで、別のプロジェクトへ移す、親から外す、詳細のほかのサブタスクの下へ入れる、ができる。詳細画面の下には、タスクのコメント（投稿者、日時、Markdown の本文、添付ファイル）を一覧し、コメントの追加と、ファイル 1 つ（100 MB まで）の添付ができる（⌘Enter か送信ボタンで送り、Enter は改行になる）。受信トレイのスレッドから「Todo にする」でタスクを作る。Todoist に接続できないときは、前回取得した内容を表示する（Todoist の個人 API トークンを使う。サイドメニューの Todo のアイコンで開き、期限（日付と時刻。時刻の無い日付は 0 時）が来た未完了の件数をそのアイコンに表示する。期限の無いタスクは数えない。接続の状態の確認と解除は、設定の「Todoist」タブで行う。一覧の見出しの ✳ のアイコンから、要約プロンプトの画面を開ける）
- Todo 画面の左のプロジェクトを右クリックすると、「移動」「アーカイブ」「削除」のメニューが出る（「インボックス」と「今日」には出ない）。「アーカイブ」はすぐにアーカイブする（タスクは Todoist に残る）。「削除」は確認のあとで、プロジェクトをセクションとタスクごと完全に消す（Todoist でも元に戻せない）。「移動」では「一番上の階層」と移せるプロジェクトが並び、選んだプロジェクトの最後のサブプロジェクト（「一番上の階層」なら一番上の最後）になる。プロジェクトの行をドラッグして別のプロジェクトに落としても、そのサブプロジェクトになり、見出し「プロジェクト」に落とすと一番上の階層に移る（自分自身、自分の下のプロジェクト、今の親には落とせない）。どれも、サブプロジェクトも一緒に動く。開いているプロジェクトをアーカイブするか消すと、一覧は「今日」に戻る
- Todo 画面の右側は、トークンの入力欄と下書きのページのあいだを除いて、いつも開いていて、2 段になっている。1 段目は、左の見出しと同じ淡い色の帯で、右端に Claude のアイコンだけがあり、押すと頼みを書く欄に移る。2 段目は Claude の見出しと操作で、その下が中身になる。右側は Claude のペインだけで、幅は仕切りで画面の 30% から 45% まで変えられる（最初はいちばん狭い画面の 30%）。左の見出しには、Todo そのものの操作（一覧のボタン、戻るボタン、見出し、タスクを開いているあいだの「Orca に渡す」、「編集」）が残る。Claude のペインでは、「年末まで週 2 件ずつ」のように言葉で頼むと、Claude がタスクの案を、名前、日付、プロジェクトのカードで返す。カードの上で名前、日付、プロジェクトを直し、「追加」を押して初めて Todoist にタスクを作る。「却下」は何も作らずにカードを閉じる。続けて頼むと、今のカードの内容も Claude に渡る。頼みを書く欄の枠の中で、この相談のモデルと effort を切り替えられる（依頼、会話、今日の日付、Todoist のプロジェクトの名前を送る。Claude Code を使えるときだけ）
- メールを Slack に貼る（詳細画面の「Slack に貼る」で専用の画面が開き、左に投稿する内容、右に Claude との会話が並ぶ。左の上は「元のメッセージ」で、スレッドの最新のメッセージの件名・差出人・日時・本文が入り、押すと編集欄になって直せる。「元の内容に戻す」で最初の文に戻せる。その下は「行うこと」で、どこに何を投稿するかのカードが番号つきで並ぶ。カードの貼り付け先は、最近使った先、参加しているチャンネルの検索、Slack のリンクから選ぶ（Claude に選ばせることもできる）か、前の番号の投稿のスレッドにする。投稿するのは、カードに書いた文面か、元のメッセージ。「＋」で行うことを足せ（未投稿は 10 件まで）、2 件目からは消せる。左下の「投稿」（複数あるときは「N 件を投稿」）で上から順に投稿し、スレッドに続ける 1 件は前の投稿への返信になる。途中で失敗するとそこで止まり、送れた分は「投稿済み」になって二度と送られない。投稿しても画面は閉じず、続きを足せる。カードに書いた `@here`、`@channel`、`@everyone` は、投稿のとき一斉メンションになる。複数のワークスペースを持て、トークンはサイドメニューの設定で追加する）
- サイドメニューは、開いている画面に合わせて、その機能のアカウントを、アイコンの下に並べる（メールとカレンダーでは Google のアカウントをカレンダーのアイコンの下に、Slack ではワークスペースを Slack のアイコンの下に出す。Todo と設定では出さない。ワークスペースの絵は、そのワークスペースでの自分のアイコン）
- サイドメニューの Slack のアイコンで Slack の画面を開く。画面の左のサイドメニューに、「未読メッセージ」（未読の件数つき）と「ウォッチ」の 2 つのボタンと、ワークスペースごとのチャンネル（参加しているパブリックとプライベート。名前順で、未読の件数つき。DM とグループ DM は出さない）が並び、ワークスペースの名前を押すと、未読の無いチャンネルを隠して畳める（畳んだ状態はアプリを開き直しても残る）。境目をドラッグして幅を変えられる。ボタンで、全ワークスペース分のメッセージの「未読」と「ウォッチ」の一覧を 1 つずつ切り替える（送信者のアイコンと名前、本文（省略せずに全部。ボットの投稿は項目ごとに書式つきで）、返信の件数と、返信した人のアイコン（5 人まで）と最終返信の時刻を出す。新着は自動で読み直す。設定の「Slack」タブの「リアルタイム更新」でワークスペースごとに App-Level Token を登録すると、Socket Mode でつなぎ、投稿・返信・変更・削除を約 1 秒で一覧と未読の件数に出す）。「未読」は、チャンネルごとにまとめ、チャンネルごとに新しい 10 件までを、古い順に日付の区切りの下に、名前の横に時刻をつけて出す（全体の上限はない）。「ウォッチ」は新しい順で、行に日時を出す。未読のメッセージは、既読になると一覧から消える。一覧の上のヘッダーには「Slack」の見出しと、「一覧に出さないチャンネル」を開く設定のアイコンだけが付く。未読の件数は Slack のアイコンにも出す（20 件を超えると `20+`。0 件のときは消える）。サイドメニューのチャンネルにマウスを乗せると出る丸にマイナスのアイコンで、そのチャンネルを一覧に出さないようにでき、設定の「Slack」タブで戻せる。しおりで、そのスレッドをウォッチでき、ウォッチしたスレッドは外すまで「ウォッチ」に残り、新しい返信があると「新しい返信 N 件」を出す
- 「未読」のチャンネルの見出しの右端のアイコン「既読にする」で、そのチャンネルの既読位置を最新の未読のメッセージまで進める（一覧に出ていない分も含む。戻せない）。そのチャンネルのスレッドの未読の返信も既読になる。スレッドは開かない。1 件ずつ既読にするチェックと、一覧全体の「すべて既読にする」はない
- 未読の返信があるスレッドは未読の段に出し、行の下の「未読の返信 N 件」で返信を開閉する（最初は開いている。ここで読んでも Slack 側のスレッドの未読は消えない）

`TSUNAGIAI_PORT` でも渡す（改名の前の名前の `COOKAPPS_PORT` にも同じ値を入れる）。アプリの PATH はシェルのものと違うので、`aws` などのコマンドはパスで書く）。スクリプトを動かす前からそのホストとポートで何かが応えるときは、スクリプトを動かさずに、使われていると伝える。アプリはそのホストとポートにつながるまで最長 2 分待ち、そこで MySQL にログインする。準備ができる前にスクリプトが終わったときと、2 分で準備できないときは、スクリプトの標準エラーの最後の行を添えて伝える。右のペインのタブの帯の先頭には「Claude」のタブがあり、作業ペインと編集ペインのどちらのアイコンで右のペインを開いても、Claude Code が動いていなければ、このタブで起動する。アプリが自分で開いたターミナルで、Orca を通さずに Claude Code を動かし、MCP サーバーは `tsunagiai-mcp` だけを渡す。スクリプトを試せるように Bash などの組み込みの道具も使え、書き込む道具とコマンドは使う前に Claude Code が確かめる。右のペインを閉じても、画面を離れても、編集ペインを閉じても Claude Code は動き続け、開き直すと同じものが出る。Claude タブの × を押すか、Claude Code が終了コード 0 で終わるとタブが消え、ほかにタブがなければ右のペインも閉じる（次に開くと起動し直す）。0 以外の終了コードで終わったときは、× を押すまでタブとメッセージが残る。編集ペインを開いている間に、Claude Code が `tsunagiai-mcp` で同じ接続を保存すると、手で直していない欄にその内容を読み込む。パスワードは OS のキーチェーンに保存し、画面には出さず、保存済みかどうかだけを出す（編集で欄を空にすると、保存したものを使う）。「接続をテスト」で、保存せずに、入力したとおりにつないで MySQL のバージョンか失敗の理由を出す（アプリで開いている接続を、開いたときと同じユーザー、スクリプト、ホスト、ポートでテストするときは、スクリプトを動かし直さずに、開いている接続の道でつなぐ）。サーバーが TLS を使えるときは使い、この Mac 以外のホストへの接続は、スクリプトの有無によらず TLS を必須にする（証明書は確かめない）。接続の一覧の行を押すと接続を開き、下にデータベース、その下にテーブル（ビューを含む）が並ぶ。接続の行の点は、接続済みで緑、接続中でオレンジ、未接続で灰色になる。データベースを押すと、作業ペインに「テーブル」「SQL」のタブを出し、「テーブル」にテーブルの一覧（名前、行数（概算）、サイズ、エンジン）を出す。一覧の行を押すか Enter で、そのテーブルを開く。データベースの行を右クリックすると、「新規クエリ」（そのデータベースの SQL タブを空の欄で開く）と「データベースを閉じる」（接続は切らずにツリーを閉じる）が出る。接続はアプリを終了するか、「切断」、接続の編集、削除で閉じ、事前スクリプトも一緒に止める。テーブルを押すと、「レコード」「構造」「SQL」のタブを出す。「レコード」は 100 行ずつ出し、フッターの左に再読み込みとコピーのアイコンと行の範囲と行数の概算、右に「最初のページ」「前のページ」、ページ番号の欄（番号を入れて Enter でそのページを開く）、行数の概算から出したページ数（「/ 約 15,062」。概算なので、最後のページが空だったり続きがあったりする）、「次のページ」「最後のページ」を出す（NULL、数値、バイナリ（大きさだけ）を見分けて出し、200 文字を超える文字列は 200 文字で切る）。「構造」は列の名前、型、NULL、キー、既定値、注釈と、列の数、エンジン、文字セットを出す。「SQL」は、押したテーブルのデータベースで、書いた 1 つの文を「実行」で動かし、結果を表で先頭の 1,000 行まで、行数と時間とともに出す（SELECT は 30 秒で MySQL が止め、35 秒で終わらないときは接続を閉じる）。レコード、構造、SQL の一覧は列の間に縦線を引き、見出しの縦線をドラッグして列の幅を変えられる（幅はアプリを閉じるまで覚える）。フッターのコピーのアイコンで、出している一覧を見出し付きのタブ区切りでコピーする（スプレッドシートにそのまま貼れる。値は画面に出ている形のまま）。作業ペインのヘッダーの右端のアイコン（編集ペインでは見出しの右端のアイコン）で、右にターミナルのペインを開け閉めする（境目はドラッグで幅を変える。編集ペインを開いている間も、そのまま残る）。ペインの＋で Orca の worktree を選ぶと、そこで Orca の普通のターミナルを開く。開いたターミナルはタブで切り替え、タブの × で閉じる（Orca の画面のタブと同じく、Orca のターミナルを閉じる）。セッションは読み取り専用で、行を足す・直す・消す操作は画面にない
- 設定の「フォント」タブで、画面ごとに書体と大きさを選ぶ。メール、カレンダー、Slack は画面ごとに、Todo は左のプロジェクト一覧と右の作業スペースを別々に、Orca はプロジェクト一覧、作業スペース（チャットとファイル）、作業スペース（ターミナル）、エディタを別々に選べる。「アプリ全体」では、設定画面、サイドメニュー、ポップアップなど、画面ごとの場所に入らない部分の書体と大きさを選び、「等幅の文字」では、コード、プロンプト、差分の書体を選ぶ。テキスト形式のメールの本文は、メールの画面の書体と大きさで出す。HTML のメールの本文は、メールが指定した書体のまま出す。選んだ書体はすぐに画面に出る。初めはどの画面も今までと同じで、Orca の作業スペースだけは Ghostty の設定に従うこともできる
- ウィンドウにタイトルバーは無く、どの画面もウィンドウの上端まで広がる。macOS の閉じる・しまう・拡大のボタンは左のアイコン列の上に乗る。各画面の上端の帯は、どの画面も同じ高さ（44px）で、中のボタンも同じ大きさにそろえてある。画面のフォントを大きくすると、帯は文字に合わせて伸びる。帯の空いた所をドラッグするとウィンドウが動き、ダブルクリックで拡大する
- Orca 画面と Todo 画面の左のプロジェクト一覧は、ボタンで閉じられる（閉じている間は、右の作業ペインかタスクの一覧がその幅まで広がる。もう一度押すと開く。状態は保存せず、起動すると開いている）。Orca 画面のボタンは、開いている間は一覧の上端の左に、閉じている間は左端のペインのタブ列の左にあり、どちらも同じ横の位置に出る。Todo 画面のボタンは一覧の上端の左にあり、閉じている間は見出しの左に移る
- Claude Code から、受信トレイの一覧・閲覧・アーカイブ・既読化・ゴミ箱への移動と、予定の一覧と、データベースの画面の接続の一覧・保存・テストを扱う（接続の保存とテストは、MCP クライアントが呼ぶたびに確認するよう、書き込みのツールとして印を付けている。パスワードは扱わず、ユーザー名、事前スクリプト、ホスト、ポートを変える保存は、スクリプトの有無によらず、保存したパスワードを消す。ローカルの MCP サーバー `tsunagiai-mcp`。設定は [Claude との連携（MCP）](mcp.md)）
